# MachineHumanAudioCybersemiotics

Foundational research for explicit machine–human audio communication: information, contextual state, uncertainty, urgency and action without dependence on performed human emotion.

## Repository status

Initial repository bootstrap, 4 October 2026. The research programme and authority documents are being prepared in a review branch. No literature review, empirical finding, scholarly validation or publication is complete at this point.

The project takes its name from Søren Brier's cybersemiotics. The name does not imply his endorsement, nor that this project's design preferences follow from his theory.
