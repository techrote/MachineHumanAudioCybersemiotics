## Model and source provenance

In a q-position repeating sampling block select a set C of m distinct offsets (lanes). Observe a complex Fourier mixture of two *known candidate* carriers with arbitrary complex amplitudes. The q possible alias positions are indexed modulo q; a known common base frequency is removed by unit-modulus row scaling. For gap d in 1,...,q-1, the two columns reduce to 1 and exp(2 pi i c d/q), c in C. The receiver knows which lanes are erased. A failed lane removes that offset in every block, not an arbitrary individual sample. This is an ideal finite, coherent model; no claim about asynchronous or real-only ADC hardware.

## Sharp arbitrary lane-erasure threshold

Define B(C) = max over primes p dividing q and residues r modulo p of |{c in C : c = r mod p}|. Define E(C) = m-B(C)-1. E=-1 means the original pattern already fails for some pair.

Two columns are dependent on a nonempty retained set K iff the phases exp(2 pi i c d/q) are constant on K, iff all c in K share a residue modulo q/gcd(q,d). This modulus is a divisor >1 of q, hence contains some prime divisor p. Thus any rank-deficient K is contained in one of the prime-residue buckets of C, so |K| <= B(C). Conversely a largest bucket modulo p gives a failing retained set of size B(C) at gap d=q/p. Therefore every erasure of at most E(C) lanes leaves rank two for every possible known pair, whereas erasing exactly E(C)+1 lanes can destroy rank. A certificate is the prime, residue, retained bucket, removed complement and gap q/p; the complex null vector for the pair (0,d) is (-exp(2 pi i r/p),1). An actual erased set can be certified without any floating point.

Let p0 be the smallest prime factor of q. Pigeonhole gives B(C)>=ceil(m/p0). The consecutive pattern 0,...,m-1 has occupancy <=ceil(m/p) for every prime p|q, attaining that bound. Hence the best guaranteed number of erased lanes over all m-lane patterns is exactly m-ceil(m/p0)-1. For q even and m=3 this is zero: no choice of three lanes can guarantee retaining two identifiable carriers after one arbitrary lane failure. For m=4, one failure can be tolerated. For prime q any two distinct lanes suffice for a known pair, and all m-lane patterns tolerate m-2 erasures. Equivalently the largest family with every two lanes jointly identifying every known pair has size p0.

Example q=12: C=(0,3,6,1) has B=3, E=0; remove 1 and the gap 4 is invisible on remaining lanes. C=(0,1,2,3) has B=2, E=1. The same acquisition count and surviving count, but different guarantees.

## Conditioning and constructive alternatives

Normalize each Fourier column by sqrt(|K|). The Gram matrix has unit diagonal and complex off-diagonal S(d)/|K|, where S(d)=sum exp(2 pi i c d/q). Its eigenvalues are 1 +/- |S(d)|/|K|. The worst normalized minimum singular value over known pairs is sqrt(1-max_d |S(d)|/|K|). For e failures minimize this value over every K subset of C of size m-e. This is a relative conditioning measure, not a claim about fixed physical acquisition energy. Absolute unnormalized inverse gain additionally includes sqrt(|K|). Exact rank and numerical conditioning are distinct.

For two lanes, coprime offset difference permutes all nonzero gaps; the worst normalized singular value is sqrt(1-cos(pi/q)). A noncoprime difference gives zero. Thus exact rank alone does not promise robustness as q grows.

For no erasures, orthogonality of finite characters gives sum over d=0,...,q-1 of |S(d)|^2=qm, with |S(0)|^2=m^2. Therefore max nonzero |S|^2 >= m(q-m)/(q-1). The upper bound on the best possible normalized singular floor is sqrt(1-sqrt((q-m)/(m(q-1)))). Equality holds precisely when all nonzero squared magnitudes are equal, equivalently all nonzero directed differences of the lane set occur equally often (inverse finite Fourier transform of |S|^2). This is the standard difference-set/Welch-bound phenomenon in this restricted Fourier model, derived here rather than asserted novel. For q=7,m=3, (0,1,3) has every nonzero directed difference exactly once, attaining sqrt(1-sqrt(2)/3). It is globally optimal by proof. The consecutive pattern has a much smaller floor.

The numerical enumeration for q=4..12,m=3..min(6,q),e in {0,1} compares every lane pattern and every retained subset at that e. Numerical ties use tolerance 1e-12, so general reported conditioning optima are finite exhaustive *numerical* results, not exact algebraic comparisons. In q=12,m=4,e=1, (0,1,4,5) improves the normalized floor from 0.29885849 to 0.50462264, though both achieve the same exact rank guarantee. Worst inverse gain for unit-normalized columns drops from 3.346 to 1.982. The best rank schedule is not necessarily best-conditioned.

## Negative cases, acoustic experiment and exaptation

Blind two-sparse identification is not guaranteed: q=4,K=(0,1,2), vectors (1,i,0,0) and (0,0,1,i) give identical observations because their difference (1,i,-1,-i) is supported in the nullspace. Yet every known two-column restriction is full rank. Arbitrary unknown supports, more than two simultaneous carriers, timing jitter, correlated erasure mechanisms and real-only measurements need separate models. Numerical floors cannot be promoted to exact proofs by agreement between floating-point solvers.
