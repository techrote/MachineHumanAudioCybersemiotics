## Model and question

Represent a routing permutation p by P with P[i,j]=1 iff p[i]=j (row i receives source j). A passive routing path M(t) is continuous, nonnegative, and doubly stochastic: every row and column sums to one. This is unity DC routing and mass conservation for nonnegative inputs, NOT conservation of Euclidean signal energy. The bottleneck is min_t sigma_min(M(t)), or sigma_min of its active columns when some inputs are stipulated zero. We ask about instantaneous recoverability of arbitrary signed source vectors, not perceptual stream separation, time-series recovery or mixing acoustics. Endpoints may be reduced to identity and a relative permutation by relabelling.

## Full routing: parity and conditioning

An odd target permutation has determinant -1, whereas identity has +1. The determinant is continuous, so every real square continuous path between these endpoints is singular somewhere, even with signed gains. Hence its best possible bottleneck is zero.

For a direct crossfade (1-t)I+tP, orthogonal diagonalization over C gives singular values |1-t+t exp(2 pi i j/k)| for each k-cycle and j=0..k-1. The squared magnitude is 1-2t(1-t)(1-cos(2 pi j/k)), minimized at t=1/2. A cycle contributes floor 0 if k even and sin(pi/(2k)) if k odd (including k=1). The full floor is the minimum across cycles.

Every even permutation admits a staged path using only 3-cycles, each with exact floor 1/2. Constructively, pick a wrong row i, find the row j holding its desired source, and pick another wrong row k. Rotate j->i, i->k, k->j. At least i is fixed, no fixed row is disturbed, and relative parity stays even, ruling out precisely two wrong rows. Repeat until done. Each local interpolation has two nontrivial singular values sqrt(1-3t(1-t)), plus ones, by the cycle calculation. Thus all even endpoints admit a nonsingular passive path; identity can of course stay at floor 1. We do not claim the number of 3-cycle stages is minimal.

There is a useful upper bound on ANY passive path between distinct permutations in dimension n>=2. A row changing its unique unit entry must pass through a row r with no entry >1/2, by continuity and disjointness of the open sets where an entry exceeds 1/2. Then ||r||_2^2 <= (1/2) sum r_j =1/2. Let u be the all-ones vector divided by n and e_i the unit row index as column. Since M preserves the all-ones vector and its transpose does too, the zero-sum subspace is invariant; M^T(e_i-u)=r^T-u. Testing this vector bounds sigma_min(M)^2 by (1/2-1/n)/(1-1/n)=(n-2)/(2(n-1)). In dimension 3 the bound is exactly 1/4, so a nontrivial even permutation has optimal bottleneck exactly 1/2, not just within polygonal paths. For n>=4 the interval [1/2,sqrt((n-2)/(2(n-1)))] is a certified bracket for nontrivial even targets, not an exact general optimum. A five-cycle has direct floor sin(pi/10) ~0.309, and two disjoint swaps have direct floor 0, both improved by staging.

## One silent socket: sharp active-channel theorem

Add one source known to be identically zero, one extra output, and restore the spare to its original position at the end. Require the FULL (n+1)x(n+1) routing to remain doubly stochastic. But evaluate only the n active columns A(t), because the spare's input is stipulated zero. This is a rectangular map from n to n+1, not invertibility of the full matrix.

At each stage, swap the vacancy (location of the zero source at a permutation endpoint) with an active source by convex interpolation. The moving active column has coefficients 1-t and t in two rows, all other active columns remain disjoint unit columns. Therefore A^T A is diagonal, with one diagonal (1-t)^2+t^2 and the rest 1. Every stage has floor 1/sqrt(2), and the left inverse's operator norm never exceeds sqrt(2). This includes odd target permutations. For a nonidentity target the floor is globally optimal even among arbitrary continuous nonnegative column-stochastic rectangular paths: some active column must change its unique unit row, hence at some t all entries are <=1/2. Its squared norm is <=1/2. Testing the corresponding input basis vector bounds sigma_min(A) <=1/sqrt(2). The construction attains that bound.

For a swap A,B, route endpoint rows as [A,B,0] -> [0,B,A] -> [B,0,A] -> [B,A,0]. The full square matrix still loses rank in each local midpoint (the difference of the moving source and spare), so the original parity obstruction is not contradicted. If the spare is not actually silent or its output is inaccessible, the active guarantee does not apply. Collapsing all outputs into one mono sum also destroys distinguishability; preserving row/column sums is not a license to ignore observation geometry.

## Minimum number of vacancy moves

Restrict discrete stages to exchanging one active token with the vacancy. For a target whose nontrivial disjoint cycles have lengths k_i, the minimum number of swaps is sum_i(k_i+1). Each cycle's k_i tokens must move at least once. The first token moved from that cycle must enter the vacancy outside the cycle, since no token from that cycle has previously moved; its final position lies inside the cycle, requiring a second move. This lower bound adds across disjoint token sets. For the upper bound move one token into the spare, then move the desired token into each vacated row in succession until the first token restores the last active position and the spare is restored. This realizes k_i+1 moves. Equivalent to known star-transposition distance (the star center is the vacancy LABEL, not a fixed spatial output). Maximum over n active tokens is floor(3n/2) for n>=2, attained by disjoint swaps when n is even and swaps plus a triple when n is odd. For n=1 the maximum is 0. This is a minimum for the stated discrete primitive, not a continuous-time latency optimum.

## Provenance and negative cases

- Birkhoff-von Neumann theorem: Mathlib documentation, Mathlib.Analysis.Convex.Birkhoff, statement doublyStochastic_eq_convexHull_perm (https://teorth.github.io/analysis/docs/Mathlib/Analysis/Convex/Birkhoff.html); read displayed theorem and summary 2026-11-24. Historical bibliographic locator (secondary, not original text read): Eric Weisstein, MathWorld, Birkhoff-von Neumann Theorem, references Birkhoff 1946 pp.147-151 and von Neumann 1953 pp.5-12 (https://mathworld.wolfram.com/Birkhoff-vonNeumannTheorem.html). We do not rely on the full convex-hull theorem for the path bounds; direct convex interpolation suffices.
- Established star sorting cost: Sorting Permutations on an n-Broom, Mathematics 12(17), 2620 (2024), https://www.mdpi.com/2227-7390/12/17/2620, section immediately preceding section 3, and Lemma 1. Read exact cost passage on 2026-11-24, not full paper; cited work [4] there not independently read. Our elementary proof is supplied above; do not claim new priority for this result.
- Live repository search for doubly stochastic, permutation/interpolation, routing/singular and crossfade found no matching issue at start; this is a bounded overlap check, not a guarantee of novelty. Switched rank-one direction was rejected because #248 already covers it. #344 signed inverse is adjacent but treats circular convolution, not paths of multiport routing.
- Negative case: allow signed coefficients and a 3-cycle can be reached by an orthogonal rotation of 120 degrees on the two-dimensional zero-sum subspace, fixing the all-ones axis. Every singular value is 1. This violates the nonnegative bound but respects the signed determinant obstruction for odd permutations. Python tests the rotation and negative entries.
- Direct interpolation between two even endpoints can be singular (two disjoint swaps); parity class is not a guarantee for an arbitrary path.
- No assertion of click-free sound, latency bound, perceptual separation, real-device safety, source recovery with unknown active support, or empirical human effect. Routing matrices are known; a left inverse can only reconstruct under that observation model. Crossfades with other constraints (equal power, restricted wiring, quantized coefficients or asynchronous updates) need separate models.
