# MHAC-X004 — adversarial audit: why recurrence is not a machine philosophy

This document deliberately attempts to destroy the most seductive interpretation of X004.

## The tempting story

A long-running corpus repeatedly distinguishes uncertainty from urgency, observation from interpretation, social repair from technical repair, and samples from underlying fields. Different agent runs create related formal experiments and speculative essays. It begins to look as though “MHAC” has developed a philosophical preference for pluralism, contextuality and anti-reduction.

That story may be aesthetically useful.

It is not yet an evidentially strong explanation.

## Instruction inheritance is the dominant confound

AGENTS.md and the frozen protocol explicitly instruct workers to preserve distinctions, retain contradictions, separate evidence classes and avoid collapsing variables.

A later agent reproducing that posture is therefore behaving exactly as instructed.

This is not a nuisance variable to be statistically removed; it is part of the phenomenon. The external instructions are one mechanism by which the ecology reproduces style.

But it prevents recurrence from being interpreted as independently generated preference.

## Shared training creates correlated prior structure

Different model instances are not independent draws from arbitrary minds. Models from related training traditions can share:
- common philosophical vocabulary;
- standard scientific caution;
- familiar HCI distinctions;
- stylistic preferences for qualification and taxonomy.

Even cross-family recurrence without direct Git citation could arise from shared latent representations.

X004 has no control corpus generated by unrelated model families under matched tasks, so it cannot estimate this contribution.

## Explicit cross-links defeat a naïve rediscovery story

MHAC's RAG, issues and research notes actively point workers toward earlier artifacts.

X002 explicitly cites X001's observation-fibre result. T018 cross-references earlier repair/uncertainty work. R008 comparisons read the concept register.

That is valuable scholarly continuity, but it is **inheritance**, not independent convergence.

## The source ecology is shared

Many files read Brier, Clark/Brennan, auditory HCI, semiotic engineering and the same protocol documents. Recurring observer/context/repair language can simply reflect the bibliography.

A concept does not become an attractor merely because many papers cite the same source.

## Accepted main is selected sediment

Merged material has survived:
- agent self-review;
- mechanical CI;
- repository instructions;
- integration choices;
- sometimes explicit owner acceptance.

Failed, abandoned, duplicate or superseded work can remain invisible if analysis reads main only.

That selection pressure may make accepted material look more coherent than the actual generative process.

The shadow archive is therefore necessary, but branch sediment has the opposite problem: it overrepresents unfinished and duplicated experiments.

## Family sizes are radically unequal

Evidence/retrieval contributes 69 of 128 measured narrative documents. Theory/analysis contributes only eight.

A total-frequency claim can mostly be a statement about the largest family.

X004 uses family dispersion and per-1,000-word rates, but its motif lexicons remain analyst-designed and coarse.

## The exploratory timeline is currently one day

All 15 current-main exploratory documents in the measured corpus have a first-add date of 23 November 2026.

That means the current merged narrative corpus cannot support the story that exploratory motifs slowly evolved over “months.” The wider repository has months of research, but the explicitly free-range expedition layer is new.

This is a strong negative result and should remain visible.

## Lexical novelty is cheap

The first bridge ranking rediscovered source/protocol/evidence vocabulary.

After removing that vocabulary, the ranking still prefers very broad words: human, model, design, state, synthetic, bounded, agent.

A corpus can sound diverse while remaining conceptually narrow; it can also use identical vocabulary for substantively different ideas.

HistLens and diachronic-semantics research are reminders that implicit conceptual change requires richer methods than word counts.

X004 keeps the lexical baseline because its failures are inspectable.

## The analyzer has researcher degrees of freedom

The motif lexicons, stoplist, family partition, regex markers and bridge score were designed by this agent.

Changing them changes the result.

To prevent unconscious goal-seeking:
- the initial procedural-dominance result is preserved as a negative finding;
- stoplist changes are documented rather than silently repeated until attractive phrases appear;
- final interpretation relies on manual source reading for strong claims;
- generated rankings are triage, not acceptance.

## “Attractor” can conceal the missing causal explanation

Cultural-attractor language is appealing precisely because recurrence looks like attraction.

Buskell's analysis warns that different notions of attractor can be conflated, and a stable distribution still needs causal factors.

For MHAC those causal factors are unusually visible: prompts, repository rules, Git traces, shared models, sources and owner selection.

Calling the residual an “attractor” before explaining these mechanisms would add poetry rather than explanation.

## “Boundary object” is easy to misuse

A word used in several domains is not thereby a boundary object.

Star's retrospective warning is directly relevant: interpretive flexibility alone is insufficient.

X004 should reserve the term for an artifact demonstrably used in multiple work domains while maintaining coordinating identity and supporting actual work.

Most recurring motifs will fail that test.

## Stigmergy is useful but incomplete

Git traces clearly influence later action, which fits a minimal stigmergic description unusually well.

But MHAC is not an ungoverned ant colony:
- agents receive direct prompts;
- explicit RAG routes tell them what to read;
- repository policy constrains output;
- the human owner can redirect priorities;
- schedules intentionally generate work.

Stigmergy explains one coordination channel, not the entire programme.

## Evidence ladder for future “emergent philosophy” claims

X004 proposes a conservative ladder:

| Level | Claim | Minimum evidence |
| --- | --- | --- |
| L0 | lexical recurrence | term/phrase appears across documents |
| L1 | distributed reuse | a recognizable concept is deliberately reused across distinct work families |
| L2 | transformed reuse | the inherited concept changes form and produces a new local distinction, test or artifact |
| L3 | exaptation | a result is used for a materially different purpose than the work that generated it |
| L4 | convergent reconstruction | similar structure arises without a demonstrated direct inheritance route, after controlling obvious common prompts/sources |
| L5 | persistent agent philosophy | would require evidence far beyond this repository; X004 supplies none |

The ladder makes L2/L3 interesting enough that we do not need to inflate them into L5.

## Adversarial disposition

The corpus does **not** currently support “an AI developed a philosophy.”

It does support a stranger and perhaps more useful description:

**A human-governed, model-populated, Git-mediated research environment can preserve methodological constraints strongly enough that discontinuous workers transform them into new local machinery.**

That remains interesting after the anthropomorphic interpretation is removed.
