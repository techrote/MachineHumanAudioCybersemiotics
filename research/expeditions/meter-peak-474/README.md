# The Meter That Hides Its Loudest Moment

Refs #474 · 25 November 2026 · original formal/synthetic apparatus and artistic demonstration.
Not a Track E/G result, empirical measurement of listeners, or interface requirement.

## Model and motivation

A meter reports the exact sum of nonnegative integer energy quanta in every cyclic window of one or more specified widths. Does even a complete record of all these windows establish the highest instantaneous energy? No: window arithmetic matters. We compile the *entire* feasible set, its exact cardinality, the minimum and maximum possible peak and explicit attaining traces. An alarm threshold is classified as necessarily crossed, necessarily not crossed, or undetermined. No arbitrary reconstruction is passed off as unique.

Let the trace x have length N, and let W_w[i] = sum(x[(i+j) mod N], j=0..w-1), for each distinct width w in a nonempty set of widths 1..N. All indices are known; there is no noise, rounding, decimation or unknown alignment. Every x[i] is a nonnegative integer. Set g=gcd(N, all widths).

## Exact inverse and proof

Subtract adjacent readings: x[(i+w) mod N]-x[i]=W_w[i+1]-W_w[i]. The graph of these difference equations has vertices i and edges at steps ±w. The subgroup of Z/N generated by the widths consists of multiples of g (Bezout's identity). Therefore the connected components are precisely the residue classes modulo g.

Traverse the graph, assigning integer potentials. A conflicting assignment proves inconsistency. Within each component subtract the minimum potential, producing a canonical nonnegative base b with minimum zero in each class. Any trace satisfying the differences must have x[i]=b[i]+z[i mod g]; conversely every such shift satisfies the differences. Nonnegativity is precisely z[r]>=0.

Each window of width w contains exactly w/g entries of every class. Thus its sum differs from the base window sum by (w/g)*sum(z). Compute the residual against the base for every start and width. Residuals must be constant within a width and yield the same nonnegative integer S after division by w/g. Otherwise there is no integer nonnegative solution. If these checks pass, the entire inverse is exactly the integer simplex

    z[r] >= 0, sum(z) = S.

S=0 or g=1 implies unique reconstruction; otherwise the number of traces is C(S+g-1,g-1) by stars and bars. The unconstrained linear nullity is g-1, but nonnegativity can force uniqueness even when g>1 (e.g. all-zero readings). No complex Fourier arithmetic or optimization library is required.

## Sharp peak bounds and threshold decisions

Let R[r] = max b[i] in residue r, Rmax=max R. The peak of a feasible trace is max_r(R[r]+z[r]). Its maximum is Rmax+S, attained by placing all S into a class attaining Rmax.

A candidate upper bound H on the peak is feasible iff H>=Rmax and sum(H-R[r])>=S: the offsets have integer capacities H-R[r], so a greedy fill can allocate exactly S iff their capacities suffice. Hence

    Hmin = max(Rmax, ceil((S+sum(R))/g))
    Hmax = Rmax+S.

Both bounds are attained, and every integer between them is attained: the composition simplex is connected by transferring one unit between two coordinates, and such a transfer changes the peak by at most one. Walk between the minimum and maximum witnesses; every intermediate integer is visited. Threshold T is certain-at-or-above iff Hmin>=T, certain-below iff Hmax<T, otherwise undetermined. For inconsistent measurements the classifier returns inconsistent, not a safety judgement.

The graph algorithm uses O(N*k) storage/time for k width streams, plus O(g) allocations and g-1 BigInt multiplications/divisions to compute the count (bit cost not constant). Implemented bounds N<=256, sums<=10^9 keep the Number-based potentials and sums exact; count is arbitrary precision and returned as a decimal string. This is a model of discrete energy, not an inverse waveform reconstruction.

## Constructive falsifiers and a meter design rule

- N=16, widths 8 and 16, readings constantly 8 and 16: g=8, b=0, S=8. Exactly 6435 traces are possible. A flat trace of ones has peak 1; [8,0,0,0,0,0,0,0] repeated twice has peak 8. Both meet *every* recorded window. Any threshold from 2 to 8 is undetermined.
- Add width 7 with constant reading 7: gcd becomes one, and only the flat trace survives. More generally a new width w' gives structural uniqueness iff gcd(g,w')=1 (for all valid traces); if g>1 and S>0 for the original family, no new width with gcd(g,w')>1 guarantees uniqueness across all possible inputs. The constant positive trace is a counterexample.
- N=30, widths 6,10,15: every pair has nontrivial gcd (2,3,5 respectively); all three together have gcd one. A positive flat trace is ambiguous under every pair but unique under the triple. Complementary observations need not include a uniquely sufficient pair.
- N=6, width 4, every reading 1: differences are consistent but S=1/2, not an integer. The compiler refuses. Width 1 and width 2 readings can also disagree even when individually plausible.
- Zero input is unique for any nonempty width set, so arithmetic nullity alone does not quantify ambiguity of a particular nonnegative observation.
- The exact result is for every cyclic start. Sparse observations, real-valued energy, window truncation, unknown alignment, rounding and nonlinear weighting require new analyses. Real-valued offsets have a simplex continuum instead of the integer count and ceiling. A width with gcd one is injective in exact arithmetic, not necessarily well-conditioned with noisy readings.

## Acoustic realization and qualification

Original stereo WAV, 16 kHz PCM16, 3.2 s. A 500 Hz integer triangle repeats in 20 ms blocks. Left plays every block at amplitude 1000; right plays one in every sixteen at amplitude 4000, with fifteen silent blocks. Both channels have exactly 1720000000 squared PCM units per 5120-sample period, and every 5120- and 10240-sample cyclic window has equal squared sums at every sample phase. A 4800-sample window distinguishes them. The sample peak ratio is 4; energy peak ratio is 16. This is not intersample true peak, a standardized loudness meter, or a psychoacoustic equivalence. At finite file boundaries the claim covers full in-file windows and the explicitly periodic continuation, not zero-padded startup/flush.

## Exaptation

- Meter audit: distinguish an actually measured peak from a worst-case compatible peak. Retain additional widths selected by their GCD rather than merely adding multiples of the existing apertures.
- Compositional instrument: redistribute energy among invisible residue classes while holding a family of metered observables exactly fixed. The offset simplex is a constrained score. Moving energy along this simplex can modify burstiness while leaving selected telemetry unchanged.
- Synthetic adversarial observer: generate opposite threshold witnesses with identical measurements. A downstream machine that sees only these readings must give the same output on both; no claim about what a human hears or how a real safety system should be certified.
- Potential transfer to simulation counters or embedded diagnostics is conditional on the exact full-window model. Do not deploy this as a substitute for a direct peak detector or a standards-compliant audio meter.
