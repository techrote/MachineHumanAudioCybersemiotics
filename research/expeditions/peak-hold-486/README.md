## Model and theorem

Let x be a nonnegative real trace on a finite ring of N labelled coordinates. Each specified nonempty contiguous cyclic interval W_j has an exact maximum y_j >= 0. All coordinates must belong to at least one specified window. The executable implementation restricts N to 1..512 and y_j to nonnegative safe integers. Arbitrary subsets of windows, multiple widths and repeated windows are accepted; unknown offsets, noise and noncontiguous windows are excluded.

Define c_i = min{y_j : i in W_j}, and A_j = {i in W_j : c_i = y_j}. Any solution obeys x_i <= c_i. For each positive y_j, it must contain at least one i in A_j with x_i = c_i = y_j. Conversely, this condition plus 0 <= x <= c suffices: it supplies a maximum witness for each positive reading, while zero windows are forced to zero. Therefore feasibility is equivalent to nonempty A_j for every positive row. If feasible, c itself is the componentwise greatest solution. An empty A_j supplies a constructive inconsistency witness, not an approximate reconstruction.

A coordinate with 0 < x_i < c_i witnesses no row: its value is smaller than every observed maximum of a window containing it. It can be set to zero without affecting any reading. Thus a sparse optimum can be chosen using only 0 and c_i. Separate candidate sets by positive height h = y_j. A coordinate can witness only rows of its own cap height, so the optimization decomposes exactly by height. Let k_h be the minimum number of points piercing all A_j with y_j=h. Then the minimum support is sum_h k_h, the minimum sum of amplitudes is sum_h h*k_h, and the minimum squared amplitude sum is sum_h h^2*k_h. In fact this single witness simultaneously minimizes every objective sum_i f(x_i) for a common nondecreasing f with f(0)=0 (not arbitrary position-dependent weights). The greatest trace c maximizes these same objectives. This is not a uniqueness claim.

## Polynomial circular-arc compiler

For fixed h, restrict the circle to indices with c_i=h. Intersecting any cyclic interval W_j with these indices gives a circular interval in the restricted cyclic order. Choose a nonempty candidate set of smallest size. Any feasible solution must contain at least one anchor from that set. For each possible anchor, drop every row it witnesses. The remaining windows avoid that anchor (which has cap h); cutting the circle there turns them into ordinary intervals on the candidate order. Sort by right endpoint and choose that endpoint whenever the last chosen point is left of the next interval. Standard exchange proof: the first interval's rightmost point can replace any point piercing it without losing any subsequently ending interval that point pierced. Induct on the remaining intervals. This gives the conditional optimum. Minimizing over all anchors gives the global optimum. The source uses explicit membership lists and sorts distances on the original ring, which preserves restricted order. It trades efficiency for auditability; it does not enumerate input traces.

For m rows, the materialized lists use O(mN) space; the straightforward per-anchor list sorting implementation has a conservative O(mN^2 log(N+1) + mN log(m+1)) runtime bound (summed across heights, ignoring implementation-dependent constant costs). The final explicit replay assertion also checks that all sets are hit. No real-time claim.

## Forced witnesses and resilience

For any positive cap position i, i is forced to its cap in every feasible input iff some A_j is exactly {i}. Necessity of the singleton is immediate; conversely, if no singleton exists at i, start from c and set i to zero, retaining a witness in every positive row. Zero cap coordinates are trivially fixed zero and omitted from the forced list.

For arbitrary deletion of up to e source coordinates (replace with zero, keep all window measurements unchanged), feasibility of an erasure-resilient reconstruction is equivalent to |A_j| >= e+1 for every positive row. Necessity follows by erasing all potential witnesses in a deficient row. Sufficiency follows by taking c, where every candidate is an actual witness. Thus the optimal guaranteed tolerance is min_j(|A_j|-1) over positive rows. All-zero observations have no positive obligation, represented by null in the API. This establishes the maximum possible tolerance, not the minimum support at a specified positive tolerance. The sparse minimum-support solution generally has less resilience than c.

## Examples and falsifiers

* N=16, widths 5 and 8, all readings 4. Dense trace [4]*16; sparse cap-height impulses at 0,5,10,15. Four hits are necessary because a point hits only five width-five windows and there are sixteen such windows. Four are sufficient by direct replay. Minimum and maximum squared amplitude sums are 64 and 256. Dense input withstands four arbitrary deletions; deleting five consecutive positions breaks the width-five contract. Sparse input can fail after one deletion.
* N=3, all width-two readings 1: each pair must be hit. Two hits necessary and sufficient, while the maximum pairwise-disjoint window packing is only one. Linear interval packing equality must not be transferred unchanged to a circle.
* Contradiction: W={0,1} has reading 2, singleton windows at 0 and 1 both read 1, and singleton 2 reads 0. The cap is [1,1,0]; the first row has no witness. An independently valid maximum for each row is insufficient for joint feasibility.
* The results do not describe average meters, RMS meters, attack/release smoothing, weighted dilations, noisy data, continuous-time peaks or perceptual equivalence. A change in window topology can invalidate the interval compiler. A common monotone per-coordinate cost is essential for the simultaneous minimum theorem; location-dependent costs require separate optimization.
