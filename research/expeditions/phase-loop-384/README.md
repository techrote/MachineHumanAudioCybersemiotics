## Model and exact phase

On a complex N-sample cyclic buffer, let T x[j]=x[j-1] and M x[j]=z^j x[j], z=exp(2 pi i/N). Execute E=T, W=T^-1, N=M, S=M^-1 in chronological order. (N as a letter denotes north; buffer length is also N by convention.) TM=z^-1 MT. At lifted position (a,b), the operator is z^k M^b T^a. A horizontal step dx changes k by -b dx; a vertical step changes b without changing k. On any lifted-closed walk, k=-sum b dx=sum a dy, the integer signed area including winding multiplicities. The equality follows by telescoping the product ab (each move changes exactly one coordinate). The full operator is z^k I, independent of the signal. Reversing a word and inverting its letters negates k for closed walks. E,N,W,S yields positive unit area. Retracing an excursion gives zero phase. This is finite Weyl algebra, not a newly discovered commutator.

## Sharp shortest loop

Given any integer signed area A, the shortest lifted-closed unit-step word has length 2 ceil(2 sqrt(|A|)), zero for A=0. Proof: let h positive horizontal and v positive vertical steps; closure gives equal negative counts. The horizontal coordinate range is at most h. The signed area sum a dy is a difference of two sums of v horizontal coordinates, hence |A| <= hv <= floor((h+v)^2/4). Thus h+v >= ceil(2 sqrt(|A|)). This covers self-intersections and retracing as well as simple loops.

For positive A put s=ceil(sqrt(4A)), a=floor(s/2), b=s-a, d=ab-A. Minimality of s implies 0<=d<a: for even s=2a the previous product maximum is a(a-1), and for odd s=2a+1 it is a^2. The rectangle with d cells removed from one corner has boundary E^a N^(b-1) W^d N W^(a-d) S^b. Its area is ab-d, and length is 2s. Negative A uses the reverse-inverse word. No approximation in this proof. The JS word materializer caps |A| at 1e9 to bound allocation; arithmetic in its supported range stays exactly representable. The associated classical minimum-polyomino-perimeter formula is not new.

For a target residue r modulo N, choose the representative A with smallest absolute value (either sign at a tie). The shortest word length follows from monotonicity in |A|. Example N=64, r=32: shortest 24 unit operations; the result is exactly -I. Endpoints and magnitudes return while the phase does not.

## Shared loops and arithmetic refusal

For several buffers with lengths n_i and phase indices r_i, the same word must satisfy A=r_i (mod n_i). The generalized CRT says this is possible iff each pair agrees modulo gcd(n_i,n_j). To see the two-congruence step, solve m t = r-a (mod n), which is solvable precisely when gcd(m,n) divides r-a, with solution modulo n/gcd(m,n); inductively combine, retaining the least common multiple period. The implementation uses BigInt and returns null on inconsistency; the nearest signed representative minimizes lifted word length. Large CRT answers are certificates, not implicitly materialized words (the materializer's cap remains). Example n=8,r=4 and n=12,r=0 yields A=12 mod 24, minimal length 14. n=8,r=0 and n=12,r=2 is impossible for any duration. This is classical CRT transferred into a common gesture compiler.

## Negative cases / transfer boundaries

A magnitude-only observer cannot distinguish any of the closed-loop outputs; phase needs a reference or phase-sensitive observation. A global phase is not an amplitude effect on the complex buffer itself. Real projection and interference are explicit observation choices. If closure means only endpoints modulo buffer size, nonzero lifted winding is allowed and this shortest-path theorem is not asserted for that enlarged problem. Arbitrary continuous moves or arbitrary signed gain operations also invalidate the unit-step cost model. Noncyclic buffers, truncation and windowing need a new operator model. No claim that physical knob motion, phase perception, machine intent or human communication is equivalent to this algebra.

Potential reuse: compile phase-only control gestures for a block-based experimental synth, use CRT refusals to diagnose incompatible multibuffer phase contracts, generate metamorphic tests of circular-shift/modulation kernels (closed loop must be a scalar operator), or map a path's signed area to a reference-sensitive interference output. In a procedural control editor, the same endpoint can represent different central states; a path recorder can retain the extra integer coordinate. A direct phase knob would be cheaper if that primitive is available.
