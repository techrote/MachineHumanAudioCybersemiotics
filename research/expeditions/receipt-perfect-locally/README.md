## 2. Model and rigidity (mathematics)

Let X be a uniform original state among N finite possibilities. A public context i specifies a graph G_i on the same X. For each edge uv of G_i, there is a possible action collapsing v onto u, otherwise leaving X unchanged. The encoder knows X and the contexts, but not the actual edge actions or their outcomes. It emits a joint tuple J=(J_1,...,J_m), drawn from an arbitrary finite joint channel p(j|x), with arbitrary correlation across context coordinates. Each authorized decoder i sees only J_i, its actual action and collapsed state; it must return X exactly for every permitted world. The observer sees the labelled entire tuple but no action outcomes, secret key or auxiliary side information. No requirement of independent random draws; no cross-context feedback. Context schedule fixed, all refer to the SAME X. If the decoder also saw the whole tuple, or had a shared key, the following obstruction need not hold.

Write V_i=(1/N) sum_t max_x p_i(t|x) and V=(1/N) sum_j max_x p(j|x) for optimal one-guess successes. Disjoint marginal supports on each edge are necessary and sufficient for zero-error authorized decoding, by the actual pair-collapse observation fibres.

**Rigidity lemma.** For any connected bipartite G_i with at least one edge, the optimum V_i is 2/N. Every channel attaining it reveals the bipartition bit exactly; indeed its row distributions are identical within each side and disjoint across sides. Proof: on any edge uv, zero-error recovery implies p_i(t|u)+p_i(t|v) <= max_x p_i(t|x) for every t, so sum of maxima >=2. Equality forces equality separately for every edge and every tag. For any used tag with maximum M>0, exactly one endpoint of each edge has mass M and the other has zero. Connectivity propagates the assignment, so each tag supports exactly one whole bipartition side, with constant mass there. A binary proper colouring attains the bound. The same proof fails for disconnected graphs: components can independently orient a tag. No alphabet limit is needed for rigidity.

For any family of such graphs, if each marginal is optimal, every observed tuple reveals the full vector of bipartition bits. Conversely emitting exactly those bits attains all local optima. The least possible joint V under all local optima is therefore the number of distinct bit signatures divided by N. The lower bound follows because one tuple cannot support states of distinct signatures; the deterministic construction attains it. Private correlated randomness cannot erase a bit that each local output determines.

## 3. Exponential separation and the exact frontier (mathematics)

For integer d>=1, take N=2^d+2 states: all d-bit data words plus two anchors A,B. Define d variable contexts and two sentinel contexts. In every context, A has bit 0 and B bit 1. Data word x has its corresponding bit x_i in variable context i, and bits 0 and 1 respectively in the two sentinel contexts. Form G_i with the edge AB and, for every data vertex, the edge to its opposite-bit anchor. Thus each G_i is a connected tree (a double star), even when one anchor has no data neighbours. All individual graphs are bipartite. Their union is the complete tripartite graph on parts {A}, {B}, and the data vertices: sentinels ensure every data vertex is adjacent to both anchors; no data-data edges exist.

Every context has local optimum 2/N. The signatures are all distinct, including the anchors because of the sentinels. Therefore imposing simultaneous local optima forces V=1, regardless of correlated private randomization and vocabulary size. Yet the universal three-symbol receipt distinguishing the two anchors and the data part decodes exactly in all contexts and has joint V=3/N. This is the unconstrained joint optimum: any triangle in the union has three pairwise-disjoint joint supports, so sum of joint column maxima >=3. The optimal common receipt can be cached and replayed. Its local vulnerability is 3/N, only 1/N worse than the context-optimal value. The ratio of forced disclosure to optimal global disclosure is N/3, unbounded.

**Sharp frontier.** Impose the cap V_i <= (2+s)/N on each variable context, where 0<=s<=1. Sentinels may be required optimal (2/N); allowing larger budgets on them cannot lower the following result. Define k=floor(ds) and theta=ds-k. For k<d,

    V*(s) = [2 + (1-theta) 2^(d-k) + theta 2^(d-k-1)] / N.

At s=1 it is 3/N. This piecewise-linear curve is exact over arbitrary finite joint channels, not merely the special erasure channel used for its witness.

Proof of lower bound: classify a marginal tag in context i as A-supported, B-supported, or anchor-free (neither anchor has positive probability). Anchor-supported types are disjoint due to edge AB. If a data vertex emits an A-supported tag it necessarily has bit 0, because every bit-1 vertex is adjacent to A; similarly B-supported implies bit 1. The sum of maxima over anchor-supported tags is >=2, since both anchor rows sum to one and have disjoint supports. Consequently the sum of maxima over anchor-free tags is <=s, bounding the probability of an anchor-free tag for EACH data vertex by s. This reasoning holds even when marginal distributions differ within a side, and does not assume a ternary original alphabet.

Every complete joint tag has support in either one anchor singleton or the data part, because joint supports must be independent in the union graph. Anchor outputs thus contribute exactly two to the sum of joint maxima. On a data-supported tuple j, let R(j) be the count of anchor-free variable coordinates. All remaining data bits are determined, so the support size is <=2^R. If w(j)=sum over data x of p(j|x), its column maximum is >=w(j)/2^R. With uniform data prior, E[R]<=ds by the marginal bound and linearity of expectation, without independence. The piecewise-linear interpolant f of the values f(r)=2^(-r), r=0,...,d, is decreasing and convex. Jensen yields E[2^(-R)]>=f(E[R])>=f(ds). Hence sum of joint maxima >=2+2^d f(ds), exactly the claimed expression.

Achievability: anchor A always emits its all-zero signature, anchor B its all-one signature. A data word emits its two sentinel bits unchanged. Independently of the data word choose R=k with probability 1-theta or k+1 with probability theta (when k=d use R=d). Uniformly choose R of the d variable positions to replace by a third tag '?'; emit the other bits unchanged. Both anchors exclude '?', so every marginal remains valid for its context's edge collapses. Bit-tag column maxima are one each and '?' has maximum E[R]/d=s; sentinel maxima sum to two. Given a data tuple exactly 2^R words are equiprobable, since mask and mask size are independent of the word. Thus every inequality in the lower bound is saturated. The mask is visible in the transcript; no secret shared seed is assumed. In the endpoint s=1 this is equivalent in joint information to the universal three-way receipt, although its sentinel marginals remain individually optimal.

Example d=4, N=18:

| s | Variable-context guessing cap | Minimum joint guessing |
| ---: | ---: | ---: |
| 0 | 2/18 | 18/18 |
| 1/4 | 2.25/18 | 10/18 |
| 1/2 | 2.5/18 | 6/18 |
| 3/4 | 2.75/18 | 4/18 |
| 1 | 3/18 | 3/18 |

The apparently small local concession is not loss of authorized accuracy (always exact); it is willingness to allow slightly greater local disclosure to greatly reduce global disclosure. This is a decision-objective reversal, not a violation of data processing. Increasing s relaxes the optimization constraint; every fixed channel still leaks at least as much through the whole tuple as through a coordinate.

## 4. Adversarial controls and intellectual consequences

Fixed-context replay from #379 retains its marginal vulnerability: repeating an identical already-valid receipt does not create new distinctions. Changing contexts destroys that generalization. Independent draws are NOT necessary for this new failure; even the best possible coupling of the individually optimal marginal channels fails. The earlier recommendation is safe only when the cached receipt remains valid for the entire action family and its cumulative observer model. The universal three-symbol receipt is a constructive repair, not a universal architectural mandate.

A missing context can remove identification; a different original in each context changes the protected variable; side information or key material changes the constraints. A receiver authorized to use the entire joint transcript, rather than a single context's receipt, also changes the feasibility problem. If a real observer sees only one context, or cannot link events to the same original, this particular joint attack need not apply. Conversely an observer who sees actual intervention results can have substantially more information. Nonuniform priors invalidate the simple uniform vulnerability formula and may change the frontier. We do not equate observer guessing with entropy, adjacent-pair total variation, anonymity of recipients, or human perceptual recognition.

**Design hypothesis / falsifier:** for repeated recoverable notifications, independently qualify each local decoder, then freeze the shared original and measure joint observer vulnerability across ALL linkable contexts; compare an optimized correlated joint policy, a cached universal receipt, and context-optimal emissions. Record context sequence, allowed decoder information, exact decoder failure, both local and joint guessing, and the price of relaxing local privacy objectives. Explicitly test whether the same cached symbol remains valid on the union of possible intervention fibres. A system that fails this synthetic control cannot infer transcript privacy from individually optimized notices. A system that passes has not established human perception or operational security. If auditability requires stronger attribution, keep that disagreement rather than silently changing the privacy objective. Exact restoration of the original may itself be unnecessary for an adequate remedy.

Interpretive bridge: the older quotient guard asks whether a distinction is needed for a declared decision; the current result shows that choosing each local quotient optimally can generate a much finer intersection than any globally sufficient common quotient. Context-sensitive minimalism can become a disclosure mechanism. This is an analogy to semiotic interpretation, not a demonstrated account of Brier or of human auditory behaviour.
