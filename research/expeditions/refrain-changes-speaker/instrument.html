The Refrain That Changes Its Speaker

One motif, different operative histories. Change the scope of any note; the raw acoustic motif does not change. This is a synthetic counter, not a command interface.

1 / Footing lane

Toggle each note between LIVE (increments the imaginary counter) and QUOTE (exhibit only).

The quiet low accompaniment is an invented audit cue, not a naturally meaningful sound. Audio is generated only after clicking Play; start at low speaker volume.

2 / Nested quotation

LIVE inside an enclosing QUOTE or REHEARSE does not advance the toy counter.

3 / Late qualification

The same four audible events have arrived, but the footer deciding their disposition has not.

This is an explicit model convention; it does not detect quotation from sound or establish the validity of any real authorization.
