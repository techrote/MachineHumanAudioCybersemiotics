## The little theatre of astonishment (fiction)

The conservatory has introduced a new grace note. It means EVEN, according to its maker. A machine plays D and the grace note; the audience is told that D was unexpectedly performed. A visitor asks: unexpected compared with what? The maker points to the volume of the grace note. The visitor asks again. The machine plays louder. The alternatives were never written on the score.

An exception marker can appear to describe an event while smuggling in a comparison class. It does not necessarily state which alternatives are salient, what scale they inhabit, whose expectations they represent, or whether a deviation was permissible. Louder astonishment is not an answer to any of these questions. The preceding repair-licence essay established a separate limitation: output-only observations cannot distinguish a licensed exception from a persistent channel inversion. This supplement considers the rhetorical infrastructure of the marker itself, not its authority.

## A finite calculus of unnamed company

Assume a finite set V of event propositions, all stipulated true to remove the additive truth issue in this narrow affirmative model. An unknown strict total order ranks them from more to less expected. This is an abstract ordering, not measured probability. A marker on x may select exactly k distinct comparison alternatives from an eligible set M_x not containing x. Every selected alternative must precede x. Its identity may be unknown to the receiver. Then x can appear after prefix S exactly when the number of members of M_x in S is at least k. Proof: choose any k of the preceding eligible members; conversely every selected member must precede x. Multiple conditions and disclosed required alternatives are conjunctions of such monotone predicates. A disclosed set T is represented by M_x=T and k=|T|. The implemented census uses one quota or no marker per target. It does not model negative even, changing context over time, ties, exclusive truth alternatives, inconsistent assertions or actual perceived salience.

**Theorem (greedy consistency and latest rank).** Starting with the empty prefix, repeatedly append any unplaced label whose predicate is satisfied. Stop when none is enabled. The terminal set is unique, regardless of choices; it is the union of all attainable prefix sets. The full order exists exactly when that terminal set is V. If it exists, every attainable prefix extends to a full order. For any x, run the same closure while forbidding x and call the result C_x. Its maximum possible 1-based rank is |C_x|+1. For distinct x,y, x is forced to precede y exactly when y is absent from C_x.

Proof: any attainable prefix can be appended in its original order to another attainable prefix, skipping labels already present. Every requisite predecessor from the second ordering is still present, by monotonicity. This produces their union as an attainable prefix and proves union closure; deleting the last label proves accessibility. In a feasible full system these sets form an antimatroid. A saturated greedy set cannot omit any member of an attainable prefix: the first omitted member of that prefix would still be enabled. Therefore the saturated set equals the union, independent of choices. The same argument holds with x forbidden. For full feasibility, appending a known valid full order with already placed labels skipped proves extendibility. Every prefix before x is contained in C_x. At the end of the forbidden closure no other label is enabled, but a full continuation exists; hence x is enabled, attains rank |C_x|+1, and the order extends. If y belongs to C_x, some feasible full order places y before x; otherwise no such order exists. QED.

The computational distinction matters. A repeated-scan closure needs at most n successful additions and a naive O(n^3) time for one quota per label (scan n predicates of cost O(n) over at most n rounds). No exponential search is necessary for feasibility or a single latest rank. Counting compatible full rankings is a different task: the subset DP starts with F(empty)=1 and adds F(S) to F(S union {x}) for each enabled x. It counts all valid orderings without double-counting, using O(2^n) storage. The CJS implementation uses integer bitsets and ordinary exact small integers for n=4 only; do not extrapolate it to huge n or overflow its count type.

## Negative sediment: a comparison can be definite without a definite comparator

Take V={A,B,C,D}, with only the D marker requiring exactly two unknown alternatives among A,B,C. D must be third or fourth, but no named pair has a forced orientation. All 24 orders satisfy the empty pairwise-precedence graph; only 12 satisfy the actual marker. The graph of mandatory pair relations is therefore not a sufficient representation. A threshold condition is a disjunction of possible witnesses, not a list of individually necessary witnesses.

There is also a genuine distinction between possible and probable. Six of the 12 orders put D third and six put it fourth. A uniform prior on compatible orders gives probability 1/2 for rank four. If instead each compatible pair of an order and a two-member scope is equally weighted, the six rank-three orders admit one scope each and the six rank-four orders admit three each. Of the 24 pairs, 18 put D last; the probability becomes 3/4. Neither model is empirical. This is a weighting choice over different latent states, not new evidence. For a general single marker with m eligible labels and j preceding eligible ones, there are binomial(j,k) possible scopes, independent of the other unmarked labels. Without an explicit scope sampling contract a probability of surprise is unjustified.

A different failure: A needs at least one of B,C before it, B needs at least one of A,C, C needs at least one of A,B. D is unconstrained. Each of the three markers can be satisfied alone; every pair can be satisfied (suspend the third and there are eight complete orders). All three cannot. The closure reaches D and stops. This is a disjunctive deadlock without a forced named precedence cycle; merely collecting more correct repetitions of those markers cannot repair it. Identifying a contradiction does not identify its culprit.

## Score for the unnamed company (original symbolic art)

Four pitch tokens A,B,C,D have fixed timbres; for a realization use four distinct pitches of one's own choosing and a short fifth tone MARK after D, with equal duration and amplitude in every edition. Order cards are explicitly written before performance, not inferred from pitch height. They list hypotheses from more to less expected.

Movement I, The Small Company: display eligible scope A,B; display order A B D C; play D, MARK. C is less expected than D and is excluded from the comparison.
Movement II, The Other Company: display scope B,C; display order B C D A; play the identical D, MARK. A is now less expected than D.
Movement III, The Full Company: display A,B,C; order A B C D; again play the identical two notes. D is now the least expected globally under the authored scale.
Movement IV, The Closed Company: hide the cards, retain the eligible universe and the fact that two alternatives were selected in editions I–II. Play D, MARK. Let an archivist enumerate the twelve compatible orders without choosing a representative. End with the spoken question 'compared with what?', or leave it printed if spoken text is unwanted.

The score is original, symbolic, and not performed or rendered as WAV in this run. Its object is to expose the comparison contract, not induce a predictable affect. A loud, harsh or dissonant marker may be aesthetically interesting but is not an authenticated record of the selected alternatives.
