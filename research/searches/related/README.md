# Related-theory search log — MHAC-R004

[Corpus memo](../../sources/related/README.md) · [Protocol §7](../../protocol/PROTOCOL-v1.md#7-track-g-theoretical-sampling-and-concept-revision) · [Data model](../../../docs/DATA_MODEL.md)

These are the retained outputs of the Track G theoretical sampling run on 13 October 2026. They record discovery and identity checks. They are **not** a systematic search, and no coverage is claimed. Read the [corpus memo](../../sources/related/README.md) before using any count here.

| Path | Contents |
|---|---|
| [`exports/RELATED-WEBSEARCH-2026-10-13.json`](exports/RELATED-WEBSEARCH-2026-10-13.json) | 31 web-search runs in four batches (R1–R4): purpose (negative, discovery, access), cluster, query, call time, and returned titles and URLs in order |
| [`exports/BRIER-REFLISTS-R004.json`](exports/BRIER-REFLISTS-R004.json) | Every reference-list entry parsed from three hashed Brier files (150, 77 and 64 entries) |
| [`exports/lookups/`](exports/lookups/) | 81 Crossref, Open Library and arXiv API responses, kept byte-for-byte, with a [manifest](exports/lookups/MANIFEST.json) giving URL, time, status and SHA-256. The 34 single-DOI work records are hashed in the manifest but not committed, because some carry publisher abstracts. |
| [`exports/ACCESS-LEDGER-R004-2026-10-13.csv`](exports/ACCESS-LEDGER-R004-2026-10-13.csv) | 38 rows: every fetch, refusal, failure and deliberate not-opened decision |
| [`records/`](records/) | 115 `search_run` records: `SRCH-R004-G01`–`G31` (web), `-LK-*`, `-LK2-*`, `-LK3-*`, `-LK4-*` (lookup rounds 1–4), and `-BRLIR2013`, `-BRLSK2015`, `-BRLGL2015AM` (Brier's lists) |
| [`records/hits/`](records/hits/) | 818 `search_hit` records, one per returned occurrence or reference entry. 167 are resolved to source records; 19 unresolved web occurrences are marked as possible Track E studies for #6. |

The records are generated by [`build_r004_records.py`](../../sources/related/scripts/build_r004_records.py). Once they are accepted, change them by appending revisions rather than by rerunning the script over existing files.
