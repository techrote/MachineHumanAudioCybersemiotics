# MHAC-T007 — Received-channel instrumental falsification prepass

**Issue:** [#41](https://github.com/techrote/MachineHumanAudioCybersemiotics/issues/41). **Status:** exploratory deterministic synthetic rehearsal, not accepted R013 vocabulary or R014 study. **Base:** `main` `423649d18c54cbf90bf7bf79d49ba69b29f03848` (2026-11-03). No human listening, device control, recruitment or accessibility certification. No frozen protocol / registry change.

## Objective and boundaries

Test whether **source-side distinctions in imaginary cues** remain instrumentally distinct under a small suite of simplified, explicit transforms. Keep event truth and semantics **external to** the waveform; a waveform hash cannot authenticate its claimed source or action. The receiver/channel may make well-formed field mappings indeterminate; amplitude, ILD, projection ratio and frame-onset count cannot stand in for auditory perception. This is deliberately distinct from symbolic composition (#34), failure taxonomy (#30) and event arbitration (#36).

## Artifacts and execution

- `SOURCES.md` — original studies/standards and counterpositions, access and reading limitations, unadjudicated publication–study–sample overlaps.
- `CUES.json` — **10 invented cues** with `source_id`, `event_id`, `state_version`, `action_id`, `truth_status` as separate fictional labels; 8000 Hz, 800 ms, zero seed/no randomness, normalized **linear** units (NOT SPL).
- `TRANSFORMS.json` — **10 specified toy conditions**: identity, half gain, mono fold-down, 13-tap causal average FIR, 320-sample reflection, 1100-Hz masker, 2/30-ms and 100/400-ms compressors, 0.14 amplitude gate and mute. These are neither a validated room nor hearing-aid emulator.
- `CASES.json` and `tests/test_t007_received_channel.py` — **25 labelled adversarial cases** + 5 additional invariants, with explicit honest nulls/undefineds, negative controls, source-truth independence, replay hashes, explicit rank reversal, compression countercase and invalid-input checks.
- `model.py` — standard-library-only deterministic waveform and independent metric calculations. Pulse groups count threshold-crossing 10-ms RMS frames at **8% of the local frame peak**; this is an arbitrary engineering rule, not a human just-noticeable threshold. Spectral contrast is a two-frequency complex projection with a relative numerical floor, not a general spectral model. An ILD becomes `null` if the spatial axis is collapsed or silent. Frame-activity and tail values may include background and reverberation, **not subjective audibility**.
- `generate.py` and `generated/SUMMARY.json` — reproducible compact feature-pair contrasts, fixture hashes and quantized PCM waveform hashes; full 45-pair × 10-transform vector table is regenerated by `model.run_all()` on demand. Signed **16-bit little-endian per-channel PCM** encodes hash bytes; quantization limits representation only.
- `REPORT.md` and `DECISION.md` — observed proxy reversals/nulls, alternatives, downstream handoff and non-goals.

Run from repo root with Python 3.11+ and no packages:

```sh
python -m unittest discover -s tests -p 'test_t007_received_channel.py' -v
python research/tangents/received-channel/generate.py --check
python research/tangents/received-channel/generate.py  # only if fixtures intentionally change
python -m unittest discover -s tests -v
python tools/validate.py
python -m tools.build_record_fixtures --check
```

The first two are T007-specific; the last three are repository-wide. All generated numbers arise from the code (not human subjects). No waveform is emitted as an audio file or played.

## Interpretation and constraints

**Operationally measurable here:** 10-ms frame-group counts, active-frame fraction, peak/RMS/crest, two-frequency projections, interaural *level* (not ITD or location), clipped sample count, late-window RMS, pairwise distances per feature and output hashes. `null` means **undefined or not measurable**, never zero discrimination. Feature scales and arbitrary thresholds are declared, no composite safety score. Frequency projections are only defined relative to the two specified bins. Reproducibility does not imply ecological validity.

**Not measured here:** detection, correct source recognition, subjective urgency, hearing-device transfer, speech understanding, polarity/action errors, first error versus final correction, listening effort, listener variability or real-world benefit. An R013/R014 study would have to specify these separately after prerequisite acceptance; real listener work belongs behind R020. **Do not promote this to Track E or cite a synthetic result as an empirical observation.**
