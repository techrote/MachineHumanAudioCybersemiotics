## Exact counterexample: an insertion plus deletion is not a bounded jitter

Let two distinct normalized four-onset words be {0,u,v,1} and {0,x,y,1}. Since the interior sets differ and each has size two, each has a private interior point a and b respectively. The receipt {0,a,b,1} is reachable from either word by deleting the other interior point and adding the other's private point. Both share the same endpoints, absolute offset and scale, so perfect knowledge of the clock and perfect timestamp accuracy do not disambiguate this receipt. This is a worst-case existence result, not an assertion about all receipts or all possible acoustic encodings. It applies to distinct four-onset words sharing the same normalized endpoints under indistinguishable replacement pulses. Extra side information, distinct pulse labels, a different code structure or other observation contracts may defeat it.

For each of the 28 unordered pairs in each of the three eight-word codebooks, construct exact integer sample positions using span = L_A L_B ceil(4800/(L_A L_B)) samples at 8 kHz, offset 800 samples. This gives 0.6–1 s whole span, integer coordinates, identical four-onset receipt, exactly one removed and one inserted onset per world, and byte-identical PCM16 receipt arrays. 84 certificates are retained in false-onset-receipt.json, including original/deleted/false/receipt positions and feasible labels. The two source interpretations have the same four-pulse synthesized receipt; pulse overlaps can affect energy, and no matched received energy across different random receipts is claimed.

## Held-out synthetic factorial

Three fixed codebooks (source8, source8_searched, robust8), seeds 1201,1709,2089 (not used in earlier search/evaluation), 16 repetitions per seed, each word and deletion. 12 conditions per book: one deletion always; insertion absent/present, warp envelope 0/5/15 ms, timestamp jitter 0/2 ms. 1,536 cases per cell; 55,296 total. One random false onset uniformly in full packet if enabled; always draw its random value to pair conditions. Scale uniform [0.6,1] seconds, translation uniform [0.1,0.2] seconds; bounded quadratic warp 4 b x(1-x), b uniform [-D,D] seconds; independent uniform timestamp noise ±J; nearest-sample rounding at 8 kHz. Duplicate quantized indices are marked invalid and included in denominators, never silently removed. Distinct timestamps of arbitrarily close spacing are otherwise considered observed; no detector, room acoustics or perceptual masking model.

Three receivers use all possible three-onset subsequences of the received three or four timestamps and all deletion triples of each word. Nearest ratio returns only a unique nearest label (ignores absolute duration). Nominal affine membership intersects all pairwise scale intervals, scale constrained to [0.6,1], translation free, with error J+0.5/rate. Warp-envelope membership uses J+D+0.5/rate, a conservative outer bound not an exact quadratic fit. It cannot wrongly identify a valid observation when assumptions hold because the true label is retained; abstention can be extensive. Both membership receivers know the possible error bound; all receivers know the deletion/insertion count contract from the receipt length. No optimization against these trials; random streams paired across conditions and codebooks in stored message order, not identical physical stimuli across codebooks.
