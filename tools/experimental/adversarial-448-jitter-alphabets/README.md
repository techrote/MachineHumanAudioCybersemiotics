## Model and operation

Run `node lab.cjs /path/to/scratch-output` (Node.js, no dependencies). Generates four original mono 8 kHz PCM16 WAV common-receipt counterexamples and qualification JSON, prints SHA-256 per WAV. Use low hardware volume. The core executed twice in isolated connector V8; the native Node wrapper and file output were not executed there. Original source words are embedded from the pinned packing proof. Qualification JSON is the twice-identical executed receipt. No external data or dependencies.

Normalize each four-onset word to unit whole span, then apply unknown positive scale a>=0.6 seconds and translation; delete exactly one onset. Each surviving timestamp has independent bounded error, then round to nearest 8 kHz sample (additional <=0.0625 ms). Receiver is given the ordered three detected timestamps, not waveform features, labels, clock or deletion identity. No false onset, overlapping-pulse detector or human perception model. Trial scales are uniform on [0.6,1.0] seconds; receiver allows all a>=0.6. Same four equal 10 ms pulse shapes at nominal duration; after deletion three pulses remain. Full26 is capacity reference, not a matched-size comparison. The three eight-word sets share equal number of symbols and pulse count; actual spectral energy under different spacings is not asserted identical beyond the chosen isolated pulse model. No training/test human data.

For surviving triples U,V with normalized spans L_U,L_V and middle ratios r,s, the source theorem gives first possible common observation at timestamp radius J=0.6 max(L_U,L_V)|r-s|/4 seconds. A codebook minimum is the minimum over distinct words and deletion indices. Search in double precision; independently formulated BigInt enumeration certifies the exact minimum of each selected set (not the global search optimum). Literal witnesses verify radius and feasibility to 1e-12 s. Use same-packet duration normalization before comparing. For each weakest pair, stretch surviving spans equally, center the offset discrepancy, and take midpoint timestamps. Both hypotheses fit exactly that receipt at the stated radius. Rounding gives the stored sample positions and additional half-sample bound. Render a single receipt from each world with identical sample coordinates and pulse renderer; compare arrays byte-for-byte. This proves ambiguity only in this model. Witness scale is not capped at 1.0; see scales in receipt, not necessarily a held-out trial.

The bounded receiver intersects intervals for a from all three pairwise differences, since translation is free and range(y-aU)<=2 eps. Return one label only if unique, otherwise abstain (including empty). All retained true labels must remain feasible at eps+half sample. Nearest ratio ignores this extra scale constraint and returns a label unless tied. No false confidence from ties. Report invalid non-increasing timestamps separately; no silently dropped denominators.
