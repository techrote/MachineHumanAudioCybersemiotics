# INST-010L — additive rotation (0.3.2 candidate)

Refs #680 / PR #681; parent 1ec7b95e40ac3cb9dfc56a78dd138808865764d3. Creative synthesis extension of #339 (f8b9bddd89c2d174b28f060bf34b42d2ca9a0e64, sections 2–3); this revision is an engineering optimization, not human evidence.

Four gain-weighted complex oscillators replace direct additive sine evaluation. Wrapped phase remains the independent reference; re-anchor each partial every 256 ticks, staggered by 64 ticks across the four partials. Configure with finite, nonnegative steps and normalized gains supplied by Engine; nonzero gain requires step below 0.45 cycles/sample. Fixed storage, copyable fade state, no allocations or callback logging. Captured pure phase voices skip unused additive work. PhaseMemory computes the seven distinct Bessel coefficients once per configuration instead of recomputing both signs. Parameter IDs, class IDs, AC01/02/03, tuning, gesture admission, envelopes, taper and output clamp unchanged. No new control or patch format.
