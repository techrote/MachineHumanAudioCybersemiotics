# INST-010F — bounded gesture archive (26 November 2026)

Refs #680 and the [pinned research #338/#339, sections 2–3](https://github.com/techrote/MachineHumanAudioCybersemiotics/blob/f8b9bddd89c2d174b28f060bf34b42d2ca9a0e64/research/expeditions/undo-needs-forecast/README.md). Creative extension of the existing finite receipt instrument, not a theorem about auditory experience.

The engine keeps the three most recent qualifying recovered states in completion order (newest first). At note-on, depth 1 uses the latest state for all three upper partials (legacy default), depth 2 uses the previous state for partial 3 only, depth 3 uses previous and third-most-recent states for partials 3 and 4. Missing history falls back to latest, initially zero. Fundamental unchanged. Cancelled, stolen-held, and too-short gestures never commit. Reset clears the archive but preserves selected depth; active notes retain their captured oscillator steps. Fixed storage, no added work per sample, no allocation. Only the native API exposes setHistoryDepth(1..3); AC01, five host IDs, plugin factory and binary version remain unchanged. Do not advertise depth as a DAW control yet.
