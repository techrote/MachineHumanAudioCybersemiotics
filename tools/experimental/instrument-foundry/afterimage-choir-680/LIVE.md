AC01 is eight bytes: ASCII magic and little-endian unsigned 32-bit word, with reserved upper bits rejected. No earlier plugin state exists. Cancellation is transient and resets on restoration. Held notes and performance memory are preserved when applying patch controls; explicit lifecycle reset clears them. Host keys without note IDs use negative channel/pitch keys; duplicate held keys and excess voices are rejected, no stealing.

Packed atomic request/published mailboxes preserve coherent discrete parameter vectors; generation acknowledges the last applied request. Non-audio state callers serialize; audio path makes one read/write per block, no mutex. This assumes serialized lifecycle calls and a single audio writer; generation wrap after 2^32 requests is not separately qualified.

## INST-010E — bounded voice replacement (26 November 2026)

The 010D exact-head b9f2381cc3d90aecf9c9f4fb17634ce3dce613eb Windows qualification (45826448731) and integrity (45826448520) both succeeded. This 0.1.1 candidate changes overflow admission, not AC01, the five stable parameter IDs, class IDs, or the receipt law. The low-level Engine retains rejection by default; Live opts into replacement. Use a free slot, then the oldest releasing slot, then oldest held slot. A held victim is cancelled and cannot later commit history. A releasing victim has already committed or cancelled; replacement does not alter its past result. Phase, weights and gain of the displaced voice are retained for a forced fade of at most approximately 5 ms. A new voice attacks at the same slope, keeping their envelope sum at most one (roundoff aside). Eight slots, at most eight extra fading voices, no allocation, lock or I/O in processing. A slot already crossfading is ineligible; if every slot is crossfading, reject rather than truncate a tail or allocate. The nine-token live map permits a spare internal token during replacement, invalidates stolen held IDs, and ignores their later note-off. Hosts that reuse the same ID or channel/pitch fallback key before an old note-off cannot disambiguate it; overlapping identical held keys remain rejected. Reset removes both active and fading voices. Ordinary note-off and 32 ms advertised tail are unchanged.
