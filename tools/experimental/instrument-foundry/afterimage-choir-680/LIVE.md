# Afterimage Choir — INST-010B live instrument candidate

Refs #680; originating research #338/#339 at f8b9bddd89c2d174b28f060bf34b42d2ca9a0e64 sections 2–3 and the score in section 5. Engineering extension of the creative synthesis interpretation; no new research or human-effect claim.

The native live engine exposes five controls: 1600 pair rank (0–27, lexicographic low/high; default 16 = 2/6), 1601 receipt (absent/fixed/preview/full), 1602 minimum duration (0–2000 ms integer), 1603 memory (0–1000 permille), 1604 cancel-release gate (while high, releases do not commit history). Automation is applied before events at the same sample offset in the candidate adapter; zero-sample calls flush parameters. The four persistent controls pack into 28 bits. AC01 is eight bytes: ASCII magic and little-endian unsigned 32-bit word, with reserved upper bits rejected. No earlier plugin state exists. Cancellation is transient and resets on restoration. Held notes and performance memory are preserved when applying patch controls; explicit lifecycle reset clears them. Host keys without note IDs use negative channel/pitch keys; duplicate held keys and excess voices are rejected, no stealing.

Packed atomic request/published mailboxes preserve coherent discrete parameter vectors; generation acknowledges the last applied request. Non-audio state callers serialize; audio path makes one read/write per block, no mutex. This assumes serialized lifecycle calls and a single audio writer; generation wrap after 2^32 requests is not separately qualified.
