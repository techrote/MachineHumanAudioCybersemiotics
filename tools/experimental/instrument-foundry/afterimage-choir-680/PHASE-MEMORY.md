Engine::setPhaseMix(0..1) is a native-only control, default zero. At note onset the selected historical states h1/h2/h3 are captured exactly as in the additive archive. Modulator/carrier ratio = 1.25 + .25*h2; phase index = .2 + .12*h1 + .06*h3 radians. Blend is phase mix times memory influence times carrier taper. Changes affect future notes only; reset clears the history, not the control. No new history commits for stolen/cancelled gestures. Existing additive output is unchanged at zero mix.

PhaseMemory approximates sin(wc*t + beta*sin(wm*t)) via 13 signed-frequency sidebands (orders -6..6, J_k(beta) coefficients, fixed ten-term-update power series). Coefficients calculated at onset; signed sidebands taper from 0.4 to 0.45 of sample rate and are removed above it, so steady oscillators do not intentionally exceed Nyquist. Envelope transients and finite precision are not claimed alias-free. Normalize by max(1, sum of absolute tapered coefficients); the existing output bound of .52 FS remains. No allocations, locks or I/O in tick. Maximum 13 additional oscillator terms per active or fading voice; onset work and storage bounded. CPU deadlines and desktop DAW not measured. Native PhaseMemory is independently reusable.
