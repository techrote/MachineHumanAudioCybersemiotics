# Afterimage Choir — INST-010A

Refs #680, #338/#339 at f8b9bddd89c2d174b28f060bf34b42d2ca9a0e64, research/expeditions/undo-needs-forecast/README.md sections 2–3 and the original unrendered score in section 5. Restricted pair-collapse encode/decode is a direct formal realization; gesture history and synthesis are creative extensions. No research acceptance or human effects claimed. Signal Foundry #675 applies the same finite model to amplitude; this instrument is independent and applies it to completed musical gestures instead.

At note-on, MIDI pitch mod 8 is the original state. A receipt is written with no bit, fixed parity bit, preview-selected distinguishing bit, or full three bits. At qualifying note-off, the collapse maps the higher member of a selected pair to the lower; decode chooses the lower if ambiguous. The pair is late-bound at release except in preview mode, which latches its trusted pair at onset. Receipt mode, minimum duration, and sounding partial ratios are note-local. No receipt is committed by a short note or explicit cancel. Most recent qualifying release in event order wins; a held voice is not retuned. History 0 is reset default, not persisted. This is not a blind forecast or recovery of the continuous waveform.

Each following voice retains its original fundamental and captures the remembered state h as partial ratios 1, 2+0.25h, 3+0.5h, 5+0.75h. Memory amount controls overtone weights. Eight shared voices, no stealing (excess notes rejected), 5 ms attack, up to approximately 30 ms release, explicit reset, no autonomous notes. Mono/dual mono, finite validated note/patch controls, tuning +/-1200 cents. Fade partials between 0.40 and 0.45 times sample rate; 0.52 FS peak bound. No allocation, lock, I/O or unbounded loop in tick; bounded sin evaluations per active voice. All calls require single-thread ownership. Render splits must be performed at event offsets by the caller; host event adapter not yet implemented.

## Build and demo

CMake 3.16+, C++17. Native only: cmake -S . -B build -DCMAKE_BUILD_TYPE=Release ; cmake --build build --config Release ; ctest --test-dir build -C Release --output-on-failure. Create an output directory and run afterimage_lab --render <directory> (Windows multi-config path build/Release/afterimage_lab.exe). Generates four 48 kHz mono PCM16 original 5 s scores. Each repeats MIDI 62 for 250 ms then 57 for 500 ms after a 50 ms gap, then 450 ms rest. First note commits, second is explicitly cancelled on release. Alternate pairs (2,6) and (1,6); absent and fixed differ on the latter, preview/full equivalent. Default minimum 80 ms, memory 0.8. The initial demo used only (2,6) and consequently absent/fixed were identical; corrected score retains both cases. No listening assessment performed.

Native GCC 14.2 Release -Wall -Wextra -Werror, CTest 1/1, 477887 checks; Clang ASan/UBSan same count, exit 0. 896 finite cases, five rates 8/44.1/48/96/192 kHz, short/cancel/overlapping gestures, late pair vs latched preview, eight-voice admission and peak bound, exact double split-block and dual mono comparisons, float silence, invalid controls, release and reset. Eight voices 480000 offline frames in 207.611 ms on the observed Linux machine; not a callback deadline guarantee. Four WAVs reproduced byte-identically within this build; preview/full identical by design.
