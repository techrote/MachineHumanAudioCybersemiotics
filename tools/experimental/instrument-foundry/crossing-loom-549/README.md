## Play

Eight shared note slots; choose Single (legacy linear glides) or Cycle (sinusoidal opposed trajectories). Each note latches the mode, spread, timing, width and identity policy/score at note-on. In Cycle mode the timing control is the full period between phase-aligned meetings; exchanges occur at its end, step 1 first, wrapping after step 16. The original Cross/Bounce selector has no effect in Cycle mode. A score with odd parity changes the source assignment after each score repetition. Both trajectories share one envelope and equal amplitude; stereo source identity can change without changing the mathematical mono sum. Polyphonic floating-point summation and separately quantized stereo outputs need not be bit-identical in mono.

## Historical 0.1.0 implementation and SDK instructions

Refs #549, #530 and draft #531 at ede894814753cbbeb815047d771674d14c24f941. The phase-aligned crossing/bouncing collision directly realizes the acoustic witness in the pinned expedition; polyphony, pitch-relative spread and stereo width are original creative extensions. No human perception, scientific priority or research acceptance claim.

Each note launches two glides with frequencies f +/- d(1-t/T) until 2T, then holds the two endpoints. Their phase difference is zero at the sample-quantized meeting T. Crossing preserves source-channel identity; bouncing swaps the source channels at T. Both have identical mono sum for a single voice, and stereo width scales only the side signal. The glide has a continuous phase but its slope changes at the endpoint; no acceleration bound is claimed. This is synthetic source-resolved stereo, not independent room propagation. Multi-voice floating point summation need not be bit-identical for mixed policies. Eight note slots, no stealing (drop overflow and duplicate active ID), five ms attack, forty ms release; each voice/channel bound .05, aggregate .4 FS. Frequency ceiling .45 sample rate, no oversampling; envelope modulation still has sidebands. No allocations or I/O in render. No host sync; all controls latch at note-on. CL01 state stores normalized float32 parameters, not notes. Unidentified notes use a channel/pitch fallback key; simultaneous duplicate fallback keys are not supported. Zero latency, conservative 41 ms release tail, mono/stereo output.
