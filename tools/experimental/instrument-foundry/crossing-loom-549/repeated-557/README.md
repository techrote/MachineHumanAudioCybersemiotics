Creative extension of the phase-aligned mono collision, not a new proof of the expedition's endpoint matching theorem. No human evidence, no authenticated identity mechanism: the score is an explicitly supplied sequence of swap decisions. A receiver observing the mono signal cannot recover it in this construction.

For sample-quantized period P seconds, center frequency f and maximum frequency deviation d, phase offset in cycles is d P / pi * sin²(pi t/P). The two phases are center phase +/- this offset. Frequency deviations are +/- d sin(2 pi t/P); at each full period both phases and frequencies agree. Select whether to exchange source-channel assignment at that boundary with the next bit of a 16-bit repeating mask, least significant bit first. The side signal changes sign, mid is unchanged. Other equal-frequency instants are not generally phase-aligned and are not allowed swap points. The carrier phase accumulator is wrapped each sample, and period position and attack age are bounded, unlike the parent's absolute phase clock. Frequency cap .45 fs; no bandlimit guarantee for modulation sidebands. Single voice, 5 ms attack / 40 ms release, output bound .05 FS per channel, width 0..1, period .025..2 seconds, spread 0..80%. No dynamic patch edits or host adapter yet; use start/tick/off, no heap or I/O in tick. Invalid sample rate rejected, parameters sanitized. Bit index and swapped parity are inspectable, but neither is authenticated or transmitted acoustically.
