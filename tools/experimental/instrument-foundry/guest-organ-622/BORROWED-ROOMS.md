# Borrowed Rooms — Guest Organ 0.3.1 performance and regression

Refs #622, #461 (Exaptation and executed miniature, pinned fb3fca1c21213b8520584108c1d65aa1db4b6cd4). Creative composition using existing note-local adoption, not a research or human-perception finding. Baseline plugin source d353a21780379b127bec4f3bbcaf2f78392ff813; original qualified Windows artifact 15083723526. No DSP, SDK, plugin version, class IDs, GO03 encoding, parameter IDs or bus changes.

One instance, six overlapping notes, each with a separately latched four-pitch motif and continuation mode. The first note is quotation-only; later notes adopt melodic, spectral or finite-FM continuations. The base remains unchanged by adoption, and a non-adopting voice must never inherit another note's rule.

Build native with the existing CMake project (C++17), run CTest, then create an existing output directory and run guest_borrowed_rooms with that directory as its only argument. Alternatively compile borrowed_rooms.cpp with g++ -std=c++17 -O2 -Wall -Wextra -Werror. The renderer is offline and may allocate; it is not an audio callback.

Outputs: eight-second 48 kHz stereo PCM16 mixed.wav (main monitor), quotation.wav (all adoption disabled), stems.wav (base left, counter right, not a monitor mix); borrowed-rooms.mid (SMF0, 480 PPQ, 120 BPM), and two 66-point CSVs of VST3 normalized automation for IDs 1200–1210. In a DAW, load MHACGuestOrgan.vst3, import the MIDI clip at 120 BPM and reproduce one CSV as stepped host automation, setting all parameters 25 ms before the corresponding onset. CSV is a reference, not a universal DAW import format. For independent routing use the plugin's optional Base and Counter mono outputs, muting the main monitor when mixing the stems. Use conservative gain. No automatic desktop-DAW or MIDI-file automation importer is claimed.

Local execution on Linux: GCC Release-style optimized warning-clean and Clang ASan/UBSan both PASS. 1,504,800 mixed frames per compiler across 44.1/48/96 kHz; 1-frame vs 257-frame partition and inverted-citation 1024-frame comparison exact; maximum six-isolated-engine sum error 4.16334e-17. All base samples match the no-adoption baseline; the first voice has zero counter energy and the other five have nonzero counter energy only after their own opening cycle. Bounds, finite values, stem reconstruction and final 50 ms exact silence pass. All six generated files are byte-identical between compilers; separate MIDI/CSV parser check passed. An initial GCC ADL conflict with std::apply was fixed before execution. This tests native control scheduling, not SDK event queues, a real DAW or callback deadlines. Previous deadline overruns and state/concurrency limitations remain open. Same-agent implementation/testing; no independent approval.

The exact upstream SDK 3.8.0 build 66 root and seven root gitlinks were re-read; no SDK used in this native renderer. Local git retrieval failed DNS.
