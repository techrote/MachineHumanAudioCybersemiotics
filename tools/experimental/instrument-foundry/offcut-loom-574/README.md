## Play

The carrier x is a sine. Define y=clip(x,-T,T), e=(x-y)*a(t), and z=y+e, where a(t)=amount*(1+cos(colour phase))/2. For 0<=a<=1, clip(z,-T,T)=y, and e is zero off the clipped support and has the sign of the clipping boundary. The reconstructed signal z is a newly constructed latent waveform, not generally the original sine x. Both outputs share one note envelope. Changing colour or amount leaves the primary exactly unchanged in the controlled split-mode native engine. This property holds per voice, not as a claim that clipping the summed polyphonic output reconstructs its summed primary.

Split: left is the primary, right the residual. Use ordinary DAW stereo separation or pan/route the channels to independent tracks; these are not separate VST buses. Reconstruct: each channel is the sum of the two components (not a unity-power pan law). In mono the adapter uses the average of L/R; split mono therefore gives half the reconstructed amplitude. All controls latch at note-on, so automation changes the next note rather than held notes. Eight note slots, drop overflow and duplicate active IDs including released notes until their release completes. Unknown IDs use channel/pitch fallback. Note tuning +/-1200 cents, 5 ms attack, 40 ms release. No host sync; bounded wrapped phase, zero declared latency, 41 ms conservative tail. Per-voice output <= .05 FS per channel; aggregate <= .4 FS per channel. No allocation or I/O in core tick/render. The clipping and modulation generate harmonics that can alias: no oversampling or bandlimited synthesis claim. The oscillator frequencies are capped at .45 sample rate, not a bound on all generated harmonics.

Starter patches (physical units): Bare Cut T=.35 amount=0 ratio=1 Split; Slow Offcut T=.35 amount=1 ratio=1 Split; Fine Offcut T=.35 amount=1 ratio=8 Split; Rejoined T=.35 amount=1 ratio=8 Reconstruct. Use modest monitor gain; no normalization in demos. OC01 state is 20 bytes: header plus four normalized IEEE float32 little-endian values. No earlier state to migrate.
