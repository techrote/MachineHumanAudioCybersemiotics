## Play and route

One shared eight-note pool handles original and nested notes (including a mixed chord); no extra voice allocation and no stealing. Every patch value is latched at note-on, after same-offset parameter points; release remains 40 ms. All existing parameter and component/controller IDs are preserved. Main output is always a monitor: original split is P/R, nested split is (P+M)/D; reconstruct duplicates the relevant sum in both main channels. Mono uses the established half-sum convention. New auxiliary buses Primary stem, Middle stem and Deep stem are mono, inactive by default, and carry **nested voices only**. Enabling or disabling aux does not alter the monitor. In a multi-output DAW enable the three aux outputs and mute the main monitor channel if listening to the stems separately; otherwise the signal is duplicated. Legacy mode sends no aux signal. On a DAW without auxiliary support use the main monitor. Actual host routing/session migration still needs audition.

| VST ID | Parameter | Normalized defaults / interpretation |
|---|---|---|
| 800–803 | Original threshold, amount, colour ratio, routing | Unchanged |
| 804 | Nested mode | 0 (legacy), 1 (nested) |
| 805 | Second cut | .2, range 0..1 of full note gain |
| 806 | Deep articulation | 1, range 0..1 |
| 807 | Deep ratio | 4/15, 1..16 carrier ratio, quantized |

OC02 state is 36 bytes, 4-byte magic then eight little-endian float32 normalized parameters. OC01's 20-byte payload migrates to legacy mode, preserving original four controls. Old versions cannot read OC02. No class ID changes. Zero algorithmic latency; release tail bound ceil(.041*sampleRate). Float32 and Float64 adapter paths. No anti-alias guarantee; high ratios and clipping can generate aliased harmonics. No energy-conservation or arbitrary polyphonic reclip claim.

## Patches and audition

Normalized patches (800..807):
- Legacy: .5, .6, 2/7, 0, 0, .2, 1, 4/15.
- Three-stem Fine: .25, 1, 0, 0, 1, .12, 1, 7/15.
- Shallow texture: .25, 1, 0, 1, 1, .24, .65, 4/15.

From this directory run cmake -S . -B build -DCMAKE_BUILD_TYPE=Release, cmake --build build --config Release, ctest --test-dir build -C Release --output-on-failure. Run the offcut_live_test executable with any argument in an empty working directory for three original 48 kHz four-second WAVs: main.wav (P+M/D), primary-middle.wav (P/M), deep.wav (D/D). All share the Fine patch and note sequence. These demonstrate native buffer routing, not a DAW render. For the plugin, use the parent locked SDK CMake instructions; install the entire MHACOffcutLoom.vst3 directory into the host's VST3 scan location (Windows default C:\Program Files\Common Files\VST3). Do not install two versions with identical class IDs simultaneously.
