# Orbit Lantern 0.1.0 — INST-011B host integration candidate

Refs #738, #264 / draft #265 at 56c107f8f4147316a588484c47be28bc8f840fbb. Creative synthesis extension, not an empirical result or the original minimum-intervention compiler. Predecessor #739 at 207fadd626ddeb1bfd51b8bbb49bced2d9770c82; this addendum supersedes the native README's no-adapter statement.

Three note-latched parameter IDs: 1810 blend 0..1000, 1811 release 10..1000 ms, 1812 tuning -100..100 cents. Defaults 500/160/0. At a sample offset apply discrete parameter points before notes, then render. No interpolation; sounding voices keep captured patch. Note-on tuning is added in cents (finite, +/-1200 max), and velocity-zero note-on releases the matching voice. Explicit host IDs and channel/pitch fallback (-1) are separate namespaces; duplicate keys and ninth simultaneous voices are refused, not stolen. Releasing voices occupy slots until silent. Stereo preserves lattice coordinates; mono is their arithmetic mean. Source supports float32/64, no audio input, zero reported latency, conservative one-second post-note release tail, reset on stop/deactivation. Bus negotiation and actual host transport have not yet been tested. No host sync required. The fixed-size host bridge and packed 32-bit state mailbox allocate no memory and use no locks/retry loop. One consumer; state requests win over concurrent end-of-block publication and apply on an audio block boundary. OL01 stays the exact 10-byte native patch format; no new state format. IDs in plugin.cpp are fixed for this candidate; check collection-wide uniqueness before binary distribution.

Build native: cmake -S . -B build -DCMAKE_BUILD_TYPE=Release; cmake --build build --config Release; ctest --test-dir build -C Release --output-on-failure. For native VST3, clone official https://github.com/steinbergmedia/vst3sdk.git, checkout 9fad9770f2ae8542ab1a548a68c1ad1ac690abe0, git submodule update --init --recursive, then configure with -DMHAC_BUILD_VST3=ON -DMHAC_VST3_SDK=<absolute-clean-SDK-checkout>. CMake 3.25+, C++17. VST3.cmake derives from the previously qualified Afterimage build foundation; it rejects wrong root, any dirty/uninitialized/moved submodules and incorrect seven named pins. Keep all applicable SDK notices with redistributed binaries. Run the official validator and actual host tests before advertising an installable bundle. Once qualified, copy the complete MHACOrbitLantern.vst3 bundle to C:\Program Files\Common Files\VST3 and rescan. The three existing OL01 example patches are native, not .vstpreset files; WAVs can already be imported in a DAW.
