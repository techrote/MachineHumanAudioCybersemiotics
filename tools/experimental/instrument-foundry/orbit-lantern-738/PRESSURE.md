# INST-011Y — Polyphonic pressure (0.5.0 candidate)

Refs #738 / #264 and draft #265 at 56c107f8f4147316a588484c47be28bc8f840fbb. Creative playable interpretation of finite-orbit synthesis, not a direct research solver or human evidence. Parent f9a8bf4fbaa7dcc24d870f3df12b855b5c063a73; the qualified 0.4.0 binary and original evidence are preserved (Windows run 46148418256, artifact 15264931441).

The VST3 adapter now accepts kPolyPressureEvent from hosts that actually forward polyphonic aftertouch. Pressure 0 restores the attack-latched orbit blend; 1 shifts that voice toward the 68-state orbit. A bounded linear slew limits full-scale motion to 5 ms (rounded up to whole samples; floating-point rounding may add one sample). Existing sustain intervention is then applied to that blend. Explicit note ID takes precedence; missing ID uses channel and pitch. Only a held voice can receive pressure, including a new held voice with a recycled ID; existing release tails cannot be retargeted. The last target continues during release. Reset or a new note initializes pressure to zero. Nonfinite/out-of-range values, unknown IDs and released-only keys are refused. No dynamic allocations, locks or I/O in the audio path. No change to the seven parameter IDs, class IDs, OL01–OL04 state formats, existing presets or SDK lock. Pressure is performance event state, not a saved control. No channel-pressure/MPE mapping or guaranteed DAW support is claimed.

## Audition

Use a host that forwards VST3 poly pressure or a poly-aftertouch MIDI controller. Lower the Orbit blend to hear the strongest timbral shift. Hold a chord, apply pressure to individual notes, then release pressure before note-off. Baseline and pressure WAVs share the existing expressive score, with five additional pressure events:
