## Musical contract

A strictly contractive integer rotation can have nonzero periodic orbits under nearest rounding. The native engine builds the exact four-state quarter turn `(a,b,q)=(0,8,9)`, start `(4,4)`, and the 68-state witness `(8,4,9)`, start `(-16,4)`. Magnitude truncation of the latter reaches zero in 25 updates; the instrument instead safely gates the periodic waveforms. It does not implement or claim the research's minimum-intervention policy. At prepare time, form DC-free Fourier series from the two coordinate sequences and normalize by the larger channel's sum of harmonic magnitudes. The maximum harmonic included at note onset is bounded by 0.45 times the sample rate. The fifth harmonic of the 68-state orbit is dominant; its cycle frequency is MIDI pitch / 5, not the requested pitch itself. For A4 the cycle is 88 Hz and the dominant line 440 Hz. Subharmonics and spectral coloration are intentional. Stereo is the pair of orbit coordinates, not a spatial perception claim.

Three note-latched controls: blend (0–1000 permille), release (10–1000 ms), tuning (-100 to +100 cents). Default 500/160/0. Five-ms attack begins at zero, bounded eight-voice polyphony, unique nonnegative note IDs, refusal of duplicate/full or out-of-band notes (no stealing), velocity (0,1]. Note-off ramps down the current envelope; repeats do not restart release. Reset clears voices. State is OL01, 10 bytes: four-byte magic, little-endian uint16 blend, release ms, cents+100. Invalid patches rejected without mutation; patch updates do not alter already admitted voices. No VST parameter IDs yet. The core supports sample-indexed events in caller order, sorted offsets, maximum 4096 events per call; malformed streams rejected before processing. Caller provides distinct stereo buffers with no overlap. Both float and double outputs. Single-thread ownership; concurrent calls unsupported. Re-prepare clears voices, retains valid patch. Eight-voice bound 0.52 FS per channel, no callback allocation, disk/network I/O or locks in the core. No latency beyond synthesis envelope; note tail bounded by captured release. 8–384 kHz admitted; 8, 44.1, 48, 96, 192 kHz exercised in score tests.

## Build and audition

From this directory: `cmake -S . -B build -DCMAKE_BUILD_TYPE=Release`, `cmake --build build --config Release`, `ctest --test-dir build -C Release --output-on-failure`. Create output directory first and run `build/orbit_lab --render out` (multi-config Windows path may be `build/Release/orbit_lab.exe`). Three original 4-second, stereo 48 kHz PCM16 scores and matching 10-byte native patch examples, not DAW .vstpreset files. Same note sequence and velocity for all three; blend 0, 500, 1000, release 240 ms, tuning 0. Four rising open-fifth/octave chords, staggered onsets, 500-ms gates. Import WAVs into a DAW for audition; there is no live DAW plugin yet. Linux native executable is tested, Windows and macOS intended but not built here. Native tests need no SDK; future adapter must obey SDK-LOCK.txt.
