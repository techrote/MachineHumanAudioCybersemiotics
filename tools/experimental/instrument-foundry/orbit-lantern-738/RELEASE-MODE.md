# Orbit Lantern 0.2.0 candidate — release mode integration

Refs #738, #264 and draft #265 (56c107f8f4147316a588484c47be28bc8f840fbb, Exact intervention compiler and acoustic mapping). Creative amplitude sonification, not direct audio-rate feedback or evidence of human effects.

The existing Live/Engine path now implements all three release modes. Parameter 1813 is stepped (normalized 0, 0.5, 1): Linear, Fixed intervention, Phase-conditioned intervention. Mode is selected at note-off, including same-sample parameter changes before note events, then latched. Duration, tuning and blend retain the existing note-on semantics. Repeated note-off does not change a release already in progress. The phase index uses the long oscillator even at zero blend. The existing eight-voice admission, output bound, tuning and mono/stereo adapter are retained. Route preparation is outside process; copying at most 61 doubles per accepted shaped note-off avoids pointer lifetime issues and dynamic allocation.

OL01 ten-byte states continue to load with mode 0 and mode 0 continues to serialize as OL01. OL02 is the same little-endian fields with magic OL02 and one additional byte (0..2). The controller and processor use the same decoder. The lock-free 32-bit mailbox uses bits 28..29 for release mode; existing fields retain their positions. Both factory class IDs and parameter IDs 1810..1812 are unchanged. Old preset generation remains the original eight linear presets; new mode can be set in host automation. OL02 is not readable by v0.1.0.

Build native with cmake -S . -B build -DCMAKE_BUILD_TYPE=Release; cmake --build build; ctest --test-dir build --output-on-failure. New mode_test exercises 3003 extended configuration roundtrips, invalid-mode rejection, mailbox publication, six sample rates and all three modes against the previous independent native release instrument, including mode changes during release and exact silence. Local Linux GCC Release 6/6 CTest and Clang ASan/UBSan mode probe 182633 checks PASS. Same-agent tests, no independent review. Existing phase release demos remain native prototype renders, not DAW output. Actual Steinberg adapter compilation, Windows validator, desktop host import, real-time deadlines and subjective listening are not established for this version.

Exact SDK pin is unchanged; official root tag 9fad9770f2ae8542ab1a548a68c1ad1ac690abe0 and seven root gitlinks verified. Local GitHub DNS failure blocks checkout; no SDK substitute.
