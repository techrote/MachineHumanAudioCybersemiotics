# INST-011K — Spectral escape

Refs #738 and #264 / draft #265 at 56c107f8f4147316a588484c47be28bc8f840fbb. Creative synthesis interpretation, not direct integer feedback or human evidence. Extends the actual Orbit Lantern Engine and native Live bridge, with no new persisted state or VST3 parameter.

At note-off call Live::offSpectral(id,channel,pitch,depth) with finite depth in [0,1]. This explicitly selects the phase-conditioned optimal route, independently of the patch mode. Note-off latches depth and trajectory. The old off() is unchanged. The amount is not yet saved or automatable by a DAW.

The interpolated normalized squared radius g controls amplitude as before. Spectral crossfade weight is depth*(1-g). At each knot the octave weight is clamp(0.5+2*(g[k]-g[k-1]),0,1), with 0.5 at the initial knot; linearly interpolate the weights. A phase-coherent stereo colour carrier has half fundamental, half octave/twelfth mixture (cosine left, sine right). Crossfade from the existing long-orbit waveform. Use only octave if the third harmonic exceeds the existing 0.45*sample-rate cutoff; preserve original waveform if octave is excluded. The short-orbit contribution is unchanged. This is a time-varying modulation and the carrier guard is not a proof of zero modulation sideband aliasing. Convex combination and original eight-voice gain retain 0.52 FS output ceiling. No allocation, locks or graph search in processing.

Reproduce: cmake -S . -B build -DCMAKE_BUILD_TYPE=Release; cmake --build build --config Release; ctest --test-dir build -C Release --output-on-failure. Create an output directory and run orbit_spectral_test with that directory as its sole argument to produce two 4s stereo 48k PCM16 WAVs and offline benchmark. Both use long-orbit blend, 800 ms release, identical two three-note chords and staggered note-offs, spectral depths 0 and 1. Start audition at conservative volume.
