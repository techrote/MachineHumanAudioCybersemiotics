## Play

The existing five parameter IDs 1810–1814 and both class IDs remain unchanged. ID 1815 is Sustain depth (0–1000 permille, default 0); ID 1816 is Sustain cycle (200–8000 ms, 1 ms increments, default 1000). Normalized mapping is depth/1000 and (cycle-200)/7800. Each note latches depth, cycle and route (MIDI pitch modulo 68) at admission. Automation at a note-on offset is applied before admission; later automation changes future notes only. Sustain continues through release. Zero depth bypasses sustain; independent release controls retain their existing semantics. This is a note-latched rather than continuous live modulator.

Three original presets are added: 15 Breathing Orbit (85%, 900 ms), 16 Slow Tidal Halo (100%, 2100 ms), 17 Flutter Lantern (75%, 200 ms). Each has a corresponding native WAV. Standard component-only .vstpreset files and generated audio ship via the existing Windows workflow on qualification. Install the entire MHACOrbitLantern.vst3 bundle into the host's VST3 folder, rescan, insert as an instrument, load a preset using the host's preset browser or set the two parameters and play held notes. No GUI dependency. Native renders are not actual DAW captures or listening assessments.

## State and callback contract

OL01/OL02/OL03 remain readable and continue to be emitted when both sustain fields have their defaults, preserving previous preset bytes. OL04 is 17 bytes: OL03 layout with magic OL04, then little-endian uint16 sustain depth at 13–14 and cycle in ms at 15–16. Old states restore depth 0 and cycle 1000. Nondefault cycle is retained even when depth is zero. Old versions are not expected to read OL04. Invalid ranges and truncated payloads are rejected before publication. Atomic patch packing uses bits 0–39 for legacy fields, 40–49 for sustain depth, 50–62 for cycle minus 200, and bit 63 for the existing pending marker. No callback heap allocations, locks, disk/network access, or graph solving added. The route bank is prepared once per setup, with bounded note-on copying and constant-work interpolation. The SDK loader/validator still requires the exact official 3.8.0 lock.
