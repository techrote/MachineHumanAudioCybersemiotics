# Reset Choir paired-engine convergence laboratory

Refs #496, #484, #485; formal foundation #424 / #425 at 6e94988ab4e6efb4779f4483983a3761e94b2c4b (research/expeditions/reset-score-424/README.md, Model and result). Measurement apparatus for the existing creative harmonic mapping. No new plugin algorithm or human evidence.

Two independent instances of the exact existing engine receive MIDI 48, velocity .8, colour .8, gain .7, identical target score and command rate. Left starts empty; right starts full. In a DAW use two Reset Choir instances with identical settings except Initial spectral fill, and hard-pan left/right; route one MIDI track to both. The offline renderer uses synchronized sample starts, which the DAW setup does not independently guarantee.

Build without SDK: g++ -std=c++17 -O2 -Wall -Wextra -Wpedantic convergence.cpp -o convergence (or MSVC /std:c++17 /EHsc). Alternatively configure the existing CMake project, build choir_convergence and run CTest. Run ./convergence for the 256-profile census; run ./convergence --render in a writable directory for CSV and four original stereo PCM16 WAVs, 48 kHz. Existing filenames are overwritten. Scores 0, 85, 170, 255 use rate .25 (41.25 ms step); the census uses normalized rate 0 (15 ms step). WAVs are bounded observation windows of sustained notes, not release-tail demos. Compare L-R, or listen to each side separately. The exact sample start alignment is a property of the offline harness.
