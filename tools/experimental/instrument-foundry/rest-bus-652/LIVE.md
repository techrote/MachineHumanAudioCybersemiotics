## Controls and performance

| ID | Control | Normalized mapping |
|---|---|---|
| 1500 | Clock domain | 0 idle, 1/3 held, 2/3 rendered, 1 manual (nearest of four) |
| 1501 | Tick period | 0.01 + 9.99 * value seconds; default 0.3 s |
| 1502 | Manual step | Rising edge at 0.5; returns to low to rearm; only advances in manual domain |

Clock domain changes preserve selector and partial tick. A changed period clears the partial tick without clearing voices or selector. Repeated identical automation values do not clear the partial tick. Manual stepping does not change already-held pitches. The clock counts accepted held voices, not physical keys that the full engine rejected or acoustic amplitude. Eight voice slots include release tails; excess notes and duplicate held IDs are rejected; velocity-zero note-on releases the ID. No voice stealing, transport sync, pitch-bend/MPE or sustain pedal. Note tuning in cents and velocity are supported. Input event bus 0, 16 MIDI channels; host-provided nonnegative note IDs take precedence, otherwise channel/pitch fallback. Ordered automation points are held at their sample offsets, then ordered note events are applied, then audio is rendered; the clock advances after the sample. No wall-clock advancement between process calls. The adapter clears voices and clock on setup, activation/deactivation and processing stop; transport seek/loop position is not inspected. Hosts that suspend processing during silence also suspend the clock. Mono or dual-mono stereo, float32/float64, zero algorithmic latency, conservative 32 ms tail. No autonomous notes. Fixed 0.48 FS bound. No custom GUI.

Example host-native patches: Silent Pentatonic (domain 0, period 0.029029029, step 0); Gate Accumulator (domain 1/3, period 0.049049049, step 0); Rendered Clock (domain 2/3, period 0.009009009, step 0); Manual Selector (domain 1, period 0.029029029, pulse step high then low). Sustain or repeat identical notes with different released durations. Four original mono demonstration WAVs are included in the native audition archive and can be regenerated using rest_demo. They are not plugin renders.

## State contract

RB01 is exactly 20 bytes: ASCII RB01 plus two little-endian IEEE binary64 normalized persistent controls. Manual-step level is transient. Invalid sizes, headers, nonfinite/out-of-range controls are rejected by the native decoder without partial mutation. Successful restore clears voices, selector, fractional/partial tick and manual edge latch; state is a patch, not a live clock/voice checkpoint. Component/controller IDs are fixed in plugin.cpp. No claims about concurrent host state calls: current bridge requires serialized state/lifecycle and processing access. No callback allocations, locks, logging or I/O in native engine; host event/automation queues are traversed in supplied order. Hard real-time timing and actual DAW automation remain unqualified.
