## Use

Build the existing CMake directory with C++17 and run CTest. From a writable directory run `organ_trajectory --render` (on Windows `organ_trajectory.exe --render`) to regenerate two stereo WAVs, an 81-row atlas, and normalized dial automation CSV; names overwrite existing files. Run `python crosscheck.py` alongside the CSV to independently represent the finite states as Boolean tuples and verify every shortest transition count. The compiler API `TrajectoryCompiler::shortest(level, signed_delta)` returns levels including initial zero, or an empty vector for an unreachable target. Invalid targets throw; construction and queries allocate, so use only off the audio thread. A compiled path is simply a list of integer dial levels, playable with the existing Manual mode, not a new VST parameter or custom preset format.

In a DAW use two instances of the already qualified MHAC Retreat Organ 0.1.0. Set both to Manual, gain 1, blend A (0), hold MIDI notes 48/55/60/64 at velocity .9 for 1.8 s. Use stepped automation of the existing Dial parameter (ID 401), normalized values from `dial-automation.csv` at 50 ms intervals. Route one mono instance hard left and the other hard right. Hold final dial 7/16 on both; rich history ends with mass A=7/8, plain path ends with A=0. For the negative control set both blends to B (1); final sustained output should match with identical note timing and phase. DAW automation import/step behavior varies; CSV is a reference, not a host-native automation format. Compare the supplied stereo WAVs from 1.0 to 1.667 s, before note-off. Avoid interpolating or skipping levels. No claim of DAW execution.

## Method and scope

Breadth-first search from both banks off at level zero, using the two 8-bit masks and current dial as the complete finite state. Each edge is a unit-cost command to any level 0–16; BFS finds minimum transition count, with ascending target level as deterministic tie order. This is not minimum physical travel, minimum reversal count, or minimum musical duration with arbitrary automation. There are 4,188 reachable states and 81 reachable (endpoint, signed relay-count difference) pairs out of 289 possible targets. Positive maximum is seven at levels 7 and 8; the shortest paths require 14 and 15 transitions respectively. Negative difference -1 is reachable only at levels 8–15. The asymmetry is a property of this pair, not of all relay models.
