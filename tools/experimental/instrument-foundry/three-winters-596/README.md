# Three Winters — native instrument laboratory

Refs #596, #422, #423. Creative musical extension of [The Metaphor That Becomes a Socket, section 3 and 4](https://github.com/techrote/MachineHumanAudioCybersemiotics/blob/03e3f121fbb2362d76db4d6cd597d27ae087ea8b/research/expeditions/metaphor-becomes-socket/README.md) and movements I–II of its original score. The discrete state contract is directly realized; the pitched rendering is an authored interpretation, not human evidence or a production communication system.

Each note produces three simultaneous sine lanes, sharing a four-token editable score. Token intervals are 0, 3, 7, 10 semitones above the note. HOLD latches the current token in lane 0, stops only lane 1's cursor, and snapshots the bank for lane 2 while its cursor continues. TICK advances moving cursors, EDIT changes the live bank, RELEASE resumes each contract without resetting phase or undoing edits. The paused cursor remains offset. HOLD is idempotent. The oscillator phases themselves never freeze. No implicit clock: the caller supplies explicit ticks and sample-offset event boundaries. Example original score: note on at 0, second note at 0.5 s, hold 1 s, edit slot 1 to token 3 at 1.5 s, tick 2 s, release 3 s, tick 4 s, note offs 5 s. At 2 s tokens are 0/0/1; at 3 s 3/0/3; at 4 s 2/3/2.

Four note slots, 12 oscillator lanes maximum, bounded fixed storage, no allocation or I/O in sample/process. Each lane is bounded by 0.2 FS, stereo mix by 0.3 FS; 5 ms full-range increment slew and attack, 40 ms maximum release. Notes beyond capacity and duplicate IDs are rejected; no abrupt voice stealing. Sample-rate setup resets score and voices. Input notes/velocities checked, pitch capped at 0.45 of sample rate. The public structs are experimental; use methods, not direct mutation of internal fields. Caller serializes events and rendering on one thread. There is no VST3 state, MIDI adapter, plugin IDs, transport, or validated DAW compatibility yet. Tuning is equal temperament, not microtuning. Very high notes at low sample rates may collapse to the same pitch because of the safety cap.

Build: cmake -S . -B build -DCMAKE_BUILD_TYPE=Release; cmake --build build --config Release; ctest --test-dir build -C Release --output-on-failure. Run winters_render demo.wav (use build/Release on multi-config systems). It produces a six-second three-channel PCM16 file, channel order latch, pause, snapshot. The core also supports a conventional stereo mix (latch left, snapshot right, pause centered at half gain). No external runtime. The SDK pin is recorded for a future adapter, not an SDK build claim.
