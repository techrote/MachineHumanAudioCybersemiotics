# Three Winters — continuous timbre socket (INST-007D)

Refs #596/#597 and [#423, section 4](https://github.com/techrote/MachineHumanAudioCybersemiotics/blob/03e3f121fbb2362d76db4d6cd597d27ae087ea8b/research/expeditions/metaphor-becomes-socket/README.md). A direct continuous-value extension of the three freeze transitions; per-oscillator harmonic morph is a creative musical application, not participant evidence.

## Contract

A four-value bank in [0,1] has its own HOLD, RELEASE, TICK and EDIT independent of the existing pitch bank. Latch captures one value; pause holds its cursor but reads live edits; snapshot preserves a bank while its cursor advances. Repeated HOLD is idempotent. The three amounts slew over a 5 ms full-range interval. Each oscillator crossfades its fundamental and second harmonic at the same phase. Second-harmonic contribution fades between normalized increments .18 and .225 and is zero above .225. At full amount the fundamental may vanish (perceived octave shift); this is not an alias-free synthesis claim. Existing voice allocation, tuning, note release, lane gains and main/stem routing are reused. The neutral amount uses the exact existing sine path. No added tail or latency, no allocations in sample(). Callers use serialized, sample-offset events. Independent clock and bank are explicit native API calls, not plugin controls yet.

## Build and audition

From the Three Winters directory: cmake -S . -B build -DCMAKE_BUILD_TYPE=Release; cmake --build build --config Release; ctest --test-dir build -C Release --output-on-failure. Alternatively configure timbre/ alone. Run timbre_demo neutral.wav neutral and timbre_demo socket.wav morph (executable in build/timbre, configuration subfolder on multi-config generators). Three channels are latch/pause/snapshot, PCM16 at 48 kHz, six seconds. Both use notes 48/55 and a 2 Hz pitch clock; separate timbre ticks every 0.5s. Bank [0,.85,.3,1], HOLD at 1s, slot 3 edit .95 at 1.5s, slot 1 edit .7 at 2s, RELEASE at 3s, note-off 5s. Neutral all-zero bank. Stereo convenience mix uses L=latch+pause/2, R=snapshot+pause/2. Suggested alternative bank [0,.25,.5,.75] for gentler changes.
