## Mechanism and proof boundary

Rather than wait for a cap overflow and attempt to reset, inspect each closed onset cluster incrementally. For each of its up to 13 unchanged clock hypotheses, demodulate the first six metadata symbols as their original v4 windows become fully available. A hypothesis is impossible under v4 if a known kind is outside 0..1, any known source/version/actor/event/sequence is zero, or more than two of these first six symbols are erased. The original GF(17) recovery changes only erased positions and refuses more than two erasures per block. For the same immutable samples, window coordinates, thresholds and retained history, these are necessary conditions: no later symbol can turn such a hypothesis into an accepted v4 packet. A cluster is dropped only if every retained hypothesis is impossible. Survivors receive exactly the original full grammar, GF(17), tag and overlap checks; no new early acceptance path. The prefix decision is not a complete frame refusal time from v4 and can change association/release timing. This is a conditional argument about the stipulated observation model, not a statement about acoustic truth, arbitrary timing reconstruction, or all possible receiver algorithms. No promotion on EOF. Original cap eight; onset-span overflow and viable-prefix floods remain unresolved. No resets in admission mode; compare sticky and v9 candidate/peak with up to four resets.

PCM allocation remains 153600 bytes, plus bounded JS objects (at most 8 x 13 x 6 prefix observations retained, 624 words; 17 frequency scores per observation, at most 325 samples each). Not a heap-free C++ adapter, embedded RAM or CPU benchmark. Repeated work on surviving metadata is extra DSP cost. No transmitter, framing, tag or contextual policy changes.
