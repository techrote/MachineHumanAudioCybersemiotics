## Experimental contract

Same semantic packet offered twice as distinct logical transactions. Both comparators use the SAME new fixed-slot envelope: 41600 PCM16 samples at 16 kHz (2.6 s), host-provided boundaries, full v2 frame at offset 64, compact v22 carrier at offset 33664. The compact carrier is repurposed, not backwards-compatible: six public digest digits over complete v1 frame bytes, role domain and independently allocated generation, followed by two base-16 digits biased by one and two GF(17) parity digits. The generation is recovered from PCM, not the expected sender record. DATA/ACK suffix uses body domain, clarification request uses request domain; ACK is rendered from decoded strict DATA and its generation. Actual nominal transmitted-frame reservation is 31360+7040=38400 samples (2.4 s) for DATA/ACK and 7040 (440 ms) for request, excluding gaps between frame blocks. This adds 440 ms to each full frame vs v22; no slot reclamation or throughput claim. Both comparators use equal 28.6 s session horizons, two attempts, three-slot timeout and identical initial conditions. Reuse always chooses generation zero; generation policy allocates independent 0..255 from retained state. Evaluator-only origin and logical offer labels determine genuine/false confirmation and wrong repair counts; not used to match control or ACK. Diagnostic receipt candidates cannot create ACKs.

The association adapter runs the inherited strict and partial diagnostic acquisition on the 33600-sample head and compact acquisition on head/tail separately. Full strict receipt requires complete supplied slot, matching public digest and near-expected onsets; body capture loss may yield a diagnostic request only if the suffix is acquired and matches. Evidence is released conservatively at slot final sample, not when the earlier head decoder completes. Explicit host slot boundary/EOF is an assumption; no unslotted acquisition, mixed-onset completeness, substantial clock drift or overlapping-transmission qualification. The public digest is finite, not an authentication code. No claim of general stale-DATA prevention or receiver-side occurrence deduplication; the demonstrated protection concerns sender-side ACK and request association.

The single-writer allocator creates one exclusive empty file per generation and fsyncs file and directory on Linux before returning. Provisioning is explicit; missing namespace, noncontiguous history and exhaustion fail closed. No reuse within 256 allocations. Reopening a directory between calls requires no volatile counter. Valid earlier snapshot restored by copying the pre-allocation namespace is undetectable; rollback reproduces both stale-request and stale-ACK failures. Power failure, concurrency, filesystem/hardware persistence and Windows directory sync unqualified. This is an experimental finite reservation, not a crash-safe production allocator. The monotonic non-reuse guarantee is conditional on intact exclusive namespace state. A bounded reuse lease is a separate trade-off, not implemented in this envelope.
