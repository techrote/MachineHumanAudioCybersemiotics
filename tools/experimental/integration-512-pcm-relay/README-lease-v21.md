## Mechanism and scope

The older first DATA is damaged by three 16-sample capture holes; a diagnostic recovery generates an actual 360 ms compact request held by the modeled channel. The older DATA is retried on ordinary timeout and a strict PCM-derived ACK retires C. A delayed request can then arrive while D is outstanding. Both policies decode the same control waveform using compact-v20 and apply first-attempt/lease guards at slot-end release. Only the quarantine policy reserves the tag through the active transaction and for 134400 samples (8.4 s) after retirement, inclusive. Colliding offers wait; exhausted capacity refuses admission. No wire changes, no diagnostic receipt promotion. The sender's local outstanding table is context, not PCM-derived identity. The scheduler's knowledge of the delayed request's origin is used solely by the evaluation metric wrongRepair, not by the resolver. The context transition and channel delays are prescribed synthetic fixtures; no general distributed scheduling or clock independence claimed.

The conditional argument: if a tag remains reserved until the last possible release of any earlier request with that tag, no newly admitted transaction can match such a request. This depends on a real bound, monotonic absolute time, intact state and exclusive reservation in the relevant namespace; these conditions are not established by acoustic parity.
