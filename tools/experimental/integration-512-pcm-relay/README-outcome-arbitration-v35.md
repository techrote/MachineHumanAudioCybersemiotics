## Contract

Reuse v33 durable receiver and v34 strict PCM outcome response (no new wire format). Four offers, two claimed sources, 12 slots of 55936 samples at 16 kHz (3.496 s each; 41.952 s horizon). One nonpreemptive job per slot, eight queued jobs maximum, three DATA attempts per offer. Source/generation/epoch and outcome revision recovered from PCM; local offer/deadline/queue and role selection are out of band. Receiver uses only decoded DATA and its committed record state to generate responses; push jobs arise on status changes to already retained records. Coalesce queued responses for the same occurrence; a push is not acknowledgement of its own delivery. Sender observes only decoded outcomes and its own offers and timers. Poll repeats DATA; push only retries initial unknown receipts; hybrid permits both with a longer provisional patience interval. Hybrid-debt uses the same hybrid contract but ranks queue jobs by age since last material sender progress for that occurrence, with FIFO tie break; centralized arbiter sees sender telemetry, so not a distributed MAC. Receipt revision remains retained-record count, not authenticated freshness. No persistence of queue or sender belief, no arbitrary stream acquisition, no independent execution witness, no actual hardware. A deadline limits DATA admission; a later response can still update belief. 'On time' means first matching report by deadline, not successful semantic execution. 'Correct final' includes correct provisional/negative statuses, not proof of action.
