## Wire contract and limitations

16 kHz PCM16 mono. v1 prefix unchanged (ordered preamble 640 samples; two 8-slot GF(17) blocks, each slot 1280 samples). Append one 8-slot block: 6 tag digits + 2 check tones with the same sum and weighted-sum constraints. Tag = SHA-256 of ASCII `MHAC-relay-v2` + NUL + 16 canonical GF(17) v1 frame symbols as bytes; interpret first four digest bytes as unsigned big-endian, reduce modulo 17^6 (=24,137,569), emit six base-17 digits least-significant first. Two GF(17) checks computed as in v1. `vectors-v2.json` includes DATA, ACK and collision witnesses with digest, symbols and tag. This is a public **unkeyed finite checksum**, not authentication, authorization, or a cryptographic security claim. Modulo mapping is not exactly uniform. No probability bound for arbitrary corruption is claimed. Frame duration grows 1.32 -> 1.96 s (+48.5%); each scheduled slot is 2 s including guard. Strict v2 configuration refuses missing/bad tag; v1 accepts the prefix, including some rejected v2 frames. No in-band version negotiation or downgrade protection. Tag check after recovered v1 semantics; acquisition thresholds and correlation remain uncalibrated. Same <=2 known erasures per block, no unknown substitution correction. Verified tag collision permits splicing despite the check; any party able to generate the checksum can generate a valid hybrid/forged ACK.

## Shared channel model

15 named cases × 3 nonpreemptive policies, ten 2-second slots each; up to two claimed sources, four offered tuples, 4-entry ACK queue; at most 2 DATA attempts per tuple, retry eligible three slots after send, no retries of superseded revisions. Return delay 1 slot (3 delayed, 2 revision), TTL 5 slots (1 expiry), expire before scheduling. `data-first` prefers eligible DATA, `ack-first` prefers ready ACK, `reserve` prefers ready ACK when slot modulo 3 equals 2, all work-conserving. No reservation guarantee under other traffic. DATA accepted only for configured route and current source revision. Actual ACK is generated from recovered DATA fields and AST; return passes PCM again. Sender acceptance uses its sent-record ledger, not receiver receipt oracle. Receiver receipt membership is evaluator-only and used after acceptance to label genuine confirmation. Historical confirmations can be stale; current revision is configured out of band, not recovered or globally synchronized. Claimed source is not authenticated. No action, resolution, human understanding, or distributed clock implemented. No arbitrary stream scheduling or durable replay ledger.

Faults are fixed fixtures by message/attempt or explicit injection slot: DATA/ACK loss, persistent loss, 1.2% resampling drift, interruption, equal-phase overlapping waveform, one block splice, seeded additive uniform noise ±600 PCM counts, delayed return, expiry, conflicting revisions, wrong-actor ACK, replay, matching forged ACK. Fixed 8 s capture windows hop 5.5 s with 2.5 s overlap, no scheduled starts passed to rescan; accepted packet sequences matched per-slot captures. Still an offline windowed rescan, not a real-time streaming receiver. Noise seed derived from 71+source*101+seq*17. Compare identical offers and fault definitions with equal channel budget, not equal actual airtime/energy. No inferential statistics or population rates.
