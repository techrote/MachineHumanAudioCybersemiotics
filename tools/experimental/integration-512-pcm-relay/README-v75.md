## Start

Extract the full archive, install Node.js 22 or compatible, then double-click `Open v75 Live.cmd` on Windows or run `node live-v75.cjs live-session75 8765` in the extracted folder. Open the printed address `http://127.0.0.1:8765/` in a browser. No external service, packages or internet required. Do not expose the server externally. Only trusted local users and a trusted session directory; do not use CLI writes simultaneously. Stop the server with Ctrl-C; restart with the same directory to resume. Choose another directory argument for a separate comparison. If abruptly killed, verify no server is running before manually removing the corresponding `.live75.lock` file; then use Recover interrupted reservation if shown. This is a cooperative single-writer lock, not a security boundary or power-loss guarantee.

## Try it

Initialize dependency arbitration with 50 seconds. Register ordered sequence 1 OPEN (source 1, generation 0); register ordered sequence 2 STOPPED (source 1, generation 1); register event sequence 1 FAULT (source 1, generation 2). Queue DATA for each with priorities 0, 1, 3 respectively. Select delay96 for STOPPED if desired. Dispatch three times: fault then OPEN then STOPPED. Queue QUERY on 1:1, select clean forward and erased return, one clean retry. Dispatch twice, inspect authenticated delivery, acknowledge it, load a generated waveform and play if desired (digital volume defaults to 12%; start with low device volume). Export state; all waveform files and per-attempt trace JSON are also in the session directory. The reporter panel is evaluation-only, not an input to the scheduler. Jobs are bounded to eight and offers to four; fresh session for new comparisons. Budget is encoded sample duration, not CPU or real acoustic time.
