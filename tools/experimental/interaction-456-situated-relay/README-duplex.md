## Contract

250 ms ticks, nonpreemptive two-tick data, one-tick ACK; exact source/version metadata supplied to oracle. At completion data is rejected if stale or erased; accepted versions enter historical ledger exactly once; duplicates regenerate ACKs but never duplicate receiver delivery. ACK can establish historical receipt after supersession, not current relevance. Current confirmation at horizon requires latest version and unexpired deadline. ACK queue FIFO cap 6, TTL 8 ticks, same-version coalescence; timeout once per first completed send, at most one retry if current and feasible, queued retry cancelled by ACK. Free comparator has one-tick delayed out-of-band ACK at zero shared cost; same loss, timeout, and forward arrivals; explicitly unmatched resource reference. Three shared policies differ only in ACK arbitration: data-first, ACK-first, alternate when both are queued. Data priority uses source debt. At a boundary prior shared completion and due free ACKs precede new offers; timeout after new offers, then expiration/admission. At horizon no new work, pending state retained. Independent integer-hash erasures are deterministic proxies, not actual acoustic channel inference. WAV illustrates all in-band emitted packets (including subsequently erased packets); free ACKs not sounded. Original tapered tones at 8 kHz, nominal peak .065, not calibrated SPL.
