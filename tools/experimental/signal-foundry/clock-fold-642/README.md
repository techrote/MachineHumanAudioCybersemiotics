## Operation

Capture 8192 stereo sample frames, then play from the completed buffer while filling the other. Four equal source quarters are mapped to positive output duration fractions proportional to exp(d*(i-1.5)+k*b[i]), i=0..3, b=(1,-1,-1,1), d=drift*(1-compensation). Durations are normalized to sum to one. Inverse piecewise-linear source coordinates resample the captured packet with linear interpolation. At full compensation the known affine log slope disappears, not the curvature. The all-triples affine quotient radius of the ideal log fractions is |k| for this family; constant normalization does not affect it. The receipt is computed from the planned fractions, not measured audio onsets. The transform changes pitch and time together; no pitch-preservation or bandlimiting guarantee.

Controls: drift and curvature [-0.5,0.5], compensation [0,1], wet [0,1], edge [0,0.25] (fraction of packet at each end, linearly blended with aligned dry); bypass. Defaults 0,0,0,1,0.03,false. Geometry and edge latch at capture boundary; wet/bypass use a 5ms full-range linear slew per sample. Mid-packet geometry edits take effect on the next capture packet, which plays one packet later. No host automation adapter yet. Mono can be used through left only; stereo channels share geometry but not samples. Finite input clamped to +/-1, nonfinite and very tiny values replaced by zero, output bounded, no feedback, fixed storage (two stereo double buffers, 262144 bytes plus controls). No allocation, lock or I/O in tick. Prepare accepts finite rates 1kHz–2MHz; reset clears history. Native latency 8192 samples, conservative tail 16384 samples. At 48kHz 170.67ms latency, so prefer compensated insert use later rather than live monitoring.

## Build and audition

C++17/CMake 3.16+, no SDK used in native targets. From this directory:

    cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
    cmake --build build --config Release
    ctest --test-dir build -C Release --output-on-failure

Run the clock_demo executable from a writable directory (on multi-config generators typically build/Release/clock_demo.exe). Four original 48kHz PCM16 stereo WAVs: clock-0 identity delayed reference; clock-1 drift .5; clock-2 drift .5 and curvature .35; clock-3 same curvature with full known-drift compensation. Identical source events, unity wet, default edge, four seconds of synthetic decaying pulses plus tail. These are reproducible native renders, not DAW recordings. No external audio. Use conservative monitor gain.
