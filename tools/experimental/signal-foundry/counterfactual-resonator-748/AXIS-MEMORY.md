# Axis Memory — independent stereo-coordinate erasure

Refs #748 and the quantized decay expedition #265 at 56c107f8f4147316a588484c47be28bc8f840fbb. Creative stereo extension, not a formal general escape solver or human evidence.

Two existing Counterfactual Resonator processors receive M=(L+R)/2 and S=(L-R)/2 separately. Each has its own pitch clock, peak/mean excitation, monitor, gain and intervention state. The wet decoder returns (M+S)/2 and (M-S)/2 with 6 dB summation headroom; the outer mix is a five-millisecond full-scale linear slew to the requested wet value. The cores are always fully wet; their individual wet/bypass inputs are overridden. At zero outer wet, finite in-range input is passed exactly after settling. AxisMemory is audio-thread-owned; configure/prepare/reset/intervention calls must be serialized with process. It does not allocate or perform I/O in process. New nonzero quantized drive can cancel an admitted escape as in the underlying processor. No arbitrary stereo independence or universal escape guarantee is asserted.

Build the existing native CMake suite (SDK optional) and run counterfactual_axis_memory via CTest. To generate four original two-second stereo PCM16 files, pass an existing directory as the executable's sole argument. Fixture: 220 Hz mid and 330 Hz side excitation for 0.5 s; at 1 s admit none, mid, side or both (axis-0/1/2/3.wav). After 1.25 s the erased axis must be zero within 1e-15 and the retained axis must match the un-erased baseline. Full erasure is silent; mid-only leaves anti-phase output, side-only leaves mono output. Gain is 0.5 per axis. Do not audition anti-phase audio by summing to mono.

Native Linux GCC optimized and Clang ASan/UBSan tested three rates, four modes, three block sizes, exact pre-command prefix and partition invariance, tail-state and intervention isolation, dry and nonfinite guards, and four byte-identical compiler-generated WAVs. Same-agent engineering tests only. Existing CR01/CR02, HM01/HM02, VST3 class/parameter IDs and SDK lock unchanged. This is a native reusable module, not a new VST3 build, parameter, bus or preset format. No host playback or listening claim.
