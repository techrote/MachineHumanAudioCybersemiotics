# FX-011R — cross-band budgeted erasure (Refs #748)

Native opt-in extension of the restricted q=9 stereo escape policy, based on draft #265 at 56c107f8f4147316a588484c47be28bc8f840fbb (Exact intervention compiler and Unbounded exact construction) and STEREO-ESCAPE.md. Each band is independently clocked. For a closed, undriven band, min(maximum absolute stereo coordinate,4) is the minimum shared truncation count. A bank-wide command admits a subset of complete escapes under a budget of 0..16 band interventions. Simultaneous truncations on different bands count separately. This is not a rate limit, global lifetime budget, amplitude-energy minimizer or proof for driven, coupled or arbitrary resonators.

Use beginBudgetedEscape(bank,budget,BudgetObjective::count or ::energy,eligibleMask=15) from the exclusive audio owner between samples. Count first maximizes the number of extinguished bands, then initial squared lattice energy; energy first reverses those priorities. Both minimize reserved intervention count next, then choose the smallest numeric mask. Energy is integer squared coordinates, not output RMS or perceived loudness. Enumerate only 15 nonempty masks; at most 60 candidate visits plus four admissions. No allocations or changes to ongoing sample processing. Capture-open, manual-pulse pending, sustained-erase, already-active or zero-state bands are ineligible. Admission zero-fills pending drive via existing optimal escape. Other independent manual/automatic commands are not included in the reservation. Cancellation does not reallocate a reservation; no promise of extinction if later commands override the policy. Selected, uninterrupted undriven policies spend the reserved cost and reach zero; unselected persistent orbits remain.

Native regression: 625 cost profiles x 5 energy patterns x 17 budgets x 2 objectives (106250 comparisons with recursive subset oracle); 102 actual stereo-bank cases across 44.1/48/96 kHz; sample-exact comparison with direct per-band admission, exact reserved/spent counts, persistent unselected bands, active/manual/open/sustained exclusion and invalid mask. GCC 14.2 optimized and Clang 17 ASan/UBSan checks pass; four original 48k PCM16 stereo WAVs reproduce byte-identically. Render with counterfactual_bank_budget path/prefix- (budgets 0,4,8,16). Fixture prepares 250 ms of constant signed stereo excitation, closes capture and waits 100 ms before rendering two seconds with short external fade-in/out and 0.5 gain. All four bands begin persistent; masks 0,1,9,15 respectively and reserved costs 0,4,8,16. Fade is a demo-only operation, not an effect change.

Native API only: existing 42 VST3 parameters, HM01, factory IDs and qualified 0.2.0 binary unchanged; no new adapter or preset claim. Exact SDK 3.8.0 pins/notice files retained, local SDK DNS blocked, Windows qualification to be checked. No desktop DAW, independent review or listener evidence.
