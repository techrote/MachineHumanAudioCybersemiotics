# FX-011W — Keyed transient erasure (Refs #748)

Creative extension of #265 at 56c107f8f4147316a588484c47be28bc8f840fbb, not a research validation. Native-only audio-key utility; no new VST3 bus, parameters or state. Existing Bank 0.3.0 binaries remain unchanged. Prepare with sample rate before use. Fixed-size peak envelope (instant attack, 5 ms exponential release), rising crossing 0.25 FS, rearm at 0.10 FS, 100 ms refractory by default. Maximum absolute stereo key level, nonfinite inputs treated as silence, clamp to unity. Held-high keys cannot repeatedly trigger; a crossing during cooldown is discarded, not deferred. Only the separate key controls admission; never feed it into the program unless intentionally routed. On a valid onset, existing planner admits new eligible band policies, never interrupts an existing policy. Budget is per onset, not per session. No allocation, locks, I/O or unbounded work in the detector or admission. No real-time timing qualification yet.

Build existing CMake project, run counterfactual_bank_transient with no argument for tests or with an existing output directory for 48 kHz stereo PCM16 program/key, four wet outputs and four exact sample-offset CSV automation files. For manual DAW replay in qualified Bank 0.3.0: use the FX-011V performance settings (110/165/220/330 Hz; gain 80%, peak 100%, selectivity 17.7/44.8/71.9/99.0%; wet 100%, energy-first, capture open, other commands off). Set budget 0, 2, 4 or 16 as desired. Program.wav is the input; Key.wav is a separate diagnostic reference, not an audible track or supported plugin sidechain. Close capture at 250 ms; valid key attacks at 500, 1000 and 1500 ms yield one-sample admission triggers; the 530 ms key is suppressed. CSV values are normalized. External output attenuation 0.5 and short fades are for audition. Reset between takes; persistent audio may continue indefinitely, lower monitoring gain. No subjective listening.

Native paired-frame oracle: detector-driven direct Bank vs manually scheduled Host automation, 12 configurations across 44.1/48/96 kHz, 2,257,200 exact stereo frames per compiler. GCC Release and Clang ASan/UBSan pass; 10 generated files byte-identical. Held-key, rearm, reset, invalid config/nonfinite, budget accounting, output bounds and full erasure tests. At 48 kHz, budget 2 cumulatively erases bands 3/4 (4 spent); budget 4 cumulatively erases all four (12 spent); budget 16 all four (12 spent). At 96 kHz budget 4 instead retains band 3 (11 spent), useful rate-dependent negative witness. No universal erasure guarantee. Existing tests remain.
