## Host contract changes

Generation-tagged SPSC request and completion mailboxes let immediate state save return a pending whole patch until acknowledged, then return the last completed automated configuration. `snapshot()` retains its completed-only meaning. State callers serialize on a non-audio mutex; lifecycle prepare/reset require stopped processing. No mutex is taken by the process callback. 38 unique known parameter queues, total maximum 4096 points, reject duplicate queues, invalid offsets, nonfinite values or overflow before touching DSP; fixed storage heap sort orders points by offset and original queue order. Same-offset persistent edits coalesce before commands. Zero-frame offset-zero parameter flush is supported. Optional null inputs are silence; null outputs advance state without storing samples. Exact in-place planar buffers supported; arbitrary overlapping buffers not supported. No interpolated automation or hard real-time timing claim. State stream reader expects exactly 43 bytes and a bounded component stream. Actual host compatibility, stream EOF behaviour, race detection and CPU qualification remain to be verified.

Existing 0.1.0 presets remain valid; the 0.2.0 bundle itself still requires exact-SDK compilation and validator inspection.

To audition: feed a note or transient with Capture on; at the desired sample close Capture and raise Optimal erase to 1, then return it to 0 to rearm. Keep sustained Erase off. The rising edge discards pending excitation and starts the restricted undriven stereo policy from FX-011M. Admission fails while capture is open, sustained erase is on or a manual pulse is pending; a rejected high is consumed, so lower and raise it again. Reopening capture, sustained erase, manual intervention or reset cancels an active policy. A held high does not retrigger. Preset loads preserve command-edge history; stopped prepare/reset clears it. At a common offset, apply coalesced persistent changes first, existing pulse/discard commands second in input order, optimal commands last, then audio. This gives manual pulses priority independent of host queue order. All old IDs and queue order semantics are preserved. No claim of globally fastest erasure: minimum interventions precede duration.
