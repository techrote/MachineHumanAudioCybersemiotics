# FX-011G — selective harmonic memory (native experiment)

Refs #748 and #264 / draft #265 at 56c107f8f4147316a588484c47be28bc8f840fbb. Creative DSP interpretation, not a direct general proof or human evidence. Builds on the qualified 0.2.0 single-resonator source 97402529ba484214d6b69baed03d7a09acf148d9. No plugin adapter, ID or CR01/CR02 state changes.

Four independent stereo processors, each with its own clock, frequency, gain, peak mix, excitation gate, erase and single/coalesced intervention. Default frequencies 110/165/220/330 Hz. Fixed 1/4 output weights; wet/bypass transitions take up to 5 ms, and per-band gain uses the underlying core slew. Muting a band via gain preserves memory. Excitation off blocks new samples but does not flush the pending window; allow a clock boundary before assuming zero drive. Erase truncates only the selected band and requires zero drive to guarantee extinction; use reset for immediate global clearing. Gates are abrupt and clock-window dependent; no frequency-selective input filtering or host automation contract yet. Set/config/pulse/process are audio-thread-owned; no cross-thread mailbox for the bank. No new serialized configuration format. Output is bounded to +/-1 FS; use low monitor levels because memory can persist indefinitely. Zero fixed transport latency does not mean zero excitation response delay.

Build from this directory: `cmake -S . -B build -DCMAKE_BUILD_TYPE=Release`, `cmake --build build --config Release`, `ctest --test-dir build -C Release --output-on-failure`. Alternatively compile harmonic_bank_test.cpp directly as C++17. Pass an existing directory as sole argument to generate retained.wav and selective.wav. Both are original 3-second PCM16 stereo renders at 48 kHz: single impulse on left, full wet, peak mix 100%, each band gain 80%; selective render erases 220 Hz at 0.5 s and all bands at 2 s. Right is silent. Compare unchanged sibling lattice states and exact final silence; not DAW captures or subjective listening.

Local Linux GCC 14.2 optimized and Clang 17 ASan/UBSan tests each 653835 checks PASS with render output. Seven sample rates, exact four-instance oracle, float/block partition comparison, bounds, invalid config/rate, nonfinite input, stereo isolation, selective extinction and bypass. Both WAVs byte-identical across builds. Offline 96 kHz/32-frame 4000-block timing: GCC max 720.418 us / 1 miss, sanitized max 1473.47 us / 3 misses; preserve negative results, no hard real-time qualification. Windows/macOS bank and actual host tests outstanding. The separately qualified 0.2.0 VST3 does NOT contain this bank. SDK pin and notices unchanged; bank consumes no SDK.
