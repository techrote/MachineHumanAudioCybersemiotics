# FX-011B — host-independent control and state bridge

Refs #748; predecessor a8fabaf8820d5a6396bd98dc96a6faf958f3717e. Creative DSP interpretation of draft #265 at 56c107f8f4147316a588484c47be28bc8f840fbb, not a human result. No changes to the resonator or CR01 patch bytes.

Call prepare/reset only when the audio thread is stopped. Submit a CR01 patch using request; one atomic 37-bit word transfers the entire persistent configuration at begin(), last request wins. Call parameter immediately before the affected sample, frame for each sample, and end() at block end. Snapshot is a coherent completed-block configuration or pending request, not guaranteed newest during an in-flight block. A single atomic word avoids torn parameter states; 64-bit lock-free atomic support is a compile-time requirement. Pulse is rising-edge only, coalesces before the next DSP tick and is never persisted. Held-high automation does not repeatedly truncate; Erase does. Reset rearms pulse.

Candidate parameter offsets from 1900: frequency, wet, gain, monitor, erase, bypass, pulse. Normalized continuous input is clamped and nonfinite values rejected. Frequency uses 40–6000 Hz integer steps, wet/gain 0–1000, monitor 0–2, flags at 0.5. Host queue parsing and final factory ID checks remain outstanding. Tail must conservatively be infinite even when current monitor is reference (can automate back to persistence). No actual VST3 adapter or binary yet. Native rate limits remain 8–384 kHz; widen and test fractional validator rates before plugin qualification.

Native build: cmake -S . -B build -DCMAKE_BUILD_TYPE=Release; cmake --build build --config Release; ctest --test-dir build -C Release -V. GCC 14.2 Release and Clang 17 ASan/UBSan Debug: 3/3 PASS each (1,125,660 existing native checks, 393,618 probe checks, 712,300 new host checks). Exact direct-DSP oracle across 160,000 stereo frames in two block partitions and both sample formats, 100,000 concurrent whole-patch submissions and 100,000 audio-thread transactions. Sanitizers were ASan/UBSan, not a race detector; actual host, deadline and independent review unqualified.
