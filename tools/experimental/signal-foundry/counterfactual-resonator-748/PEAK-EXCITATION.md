# FX-011E — Native peak-aware excitation

Refs #748 and draft #265 at 56c107f8f4147316a588484c47be28bc8f840fbb. Creative DSP extension to the driven quarter-turn model, not an undriven proof or human evidence. Base 59c8e8206c33496e1ad71a9b3582593c6339368b. Previous exact-SDK Windows qualification 45941262518 and integrity 45941262575 passed.

The native Processor now accepts setPeakMix(0..1000), default zero. At each existing clock tick, drive = round((1-m)*12*mean + m*12*signedPeak), m = permille/1000. The earliest equal-magnitude peak wins; both paths receive identical integer drive. Each channel's accumulator is independent and cleared each tick/reset. Mix is sampled at window close, including already-collected samples; no new delay line or callback allocation. Zero mix preserves the original arithmetic path. Invalid mix leaves configuration intact. Reset preserves the chosen mix, as with other controls. Native clients must restore it explicitly: CR01 and VST3 parameters are unchanged. The existing plugin still selects zero mix; do not advertise these WAVs as plugin renders.

Build and run: cmake -S . -B build -DCMAKE_BUILD_TYPE=Release; cmake --build build; ctest --test-dir build --output-on-failure. Create an output directory and run counterfactual_peak_test <directory> (on Windows use the matching configuration executable). Three 2-second stereo 48 kHz PCM16 files use +1 FS left impulse at sample 0 and -0.8 FS right impulse at sample 12000, frequency 250 Hz, wet 100%, gain 80%, persistent monitor. Peak mix 0/250/1000; native patches are those settings, not new serialized presets. Lower monitoring levels before audition: persistent states may sustain indefinitely. Erase or reset extinguishes them.

Measured native peak / final 50 ms RMS (FS): 0 / 0; 0.15 / 0.0866119; 0.6 / 0.115483. The original averaged mode rejects these sparse impulses; the new mode excites a memory. Peak detection is not a transparent reconstruction: sign selection is nonlinear, may emphasize isolated noise and may collapse opposite-sign transients in the same window. The original dead zone remains in legacy mode. Reference and discrete paths still share excitation; the continuous monitor is no longer a linear-input reference in nonzero peak mode.
