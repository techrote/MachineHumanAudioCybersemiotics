# Counterfactual Resonator 0.2.0 — peak mode integration (FX-011F)

Refs #748, #264 and draft #265 at 56c107f8f4147316a588484c47be28bc8f840fbb. Creative DSP interpretation, not an empirical result. Extends FX-011E (11d783d85f4e750dcac1f7b0c770bdde6dd636c8). Prior README, HOST-BRIDGE, VST3 and PEAK-EXCITATION notes describe historical revisions; this document supersedes their parameter/state counts.

## Contract

Parameter 1907 (Peak excitation mix, normalized 0..1, 1000 steps) selects the blend of interval average and earliest signed absolute peak. Zero retains legacy arithmetic. The value at the closing clock tick governs the completed window, including transients preceding the automation point. This is intentional window-level control, not per-sample interpolation. Other IDs 1900–1906, processor/controller IDs, sample rate admission, mono/stereo, Float32/64, zero fixed latency and conservative infinite tail are unchanged. Reset clears audio memory but retains peak mix. Erase still operates on discrete feedback, not the continuous reference. Peak capture is nonlinear; it can emphasize noise and can preserve only one signed peak per interval. Start with low monitoring levels, use Erase or reset to clear persistent resonances.

CR01 is the original 12-byte little-endian configuration. CR02 uses the same fields at bytes 4–11, magic CR02 and a uint16 peak mix at offsets 12–13 (0..1000). CR01 restores peak mix zero. Saving a zero mix emits byte-identical CR01; a nonzero mix emits CR02. Old versions cannot read CR02. The legacy encode/decode helpers are CR01-only; use encodeState/decodeState or Host::save for complete state. The atomic configuration grows from 37 to 47 bits, still one lock-free uint64. No pulse, phase or live audio state is serialized. Snapshot can be the previous completed block during admission, not a guarantee of linearizable live automation readback. The native state decoder rejects wrong lengths, magic, flags and out-of-range controls without altering the destination. The adapter reads the declared state prefix; trailing host stream bytes are not interpreted.

## Reproduction

Build as in VST3.md using the exact SDK root and seven pinned gitlinks in SDK-PIN.txt. Native CTest needs no SDK. Create Audio and Presets directories in the output directory and run counterfactual_peak_host with that directory as its sole argument (no argument runs tests without files). Three component-only presets (88 bytes for CR01, 90 for CR02) and stereo PCM16 recordings use 250 Hz, full wet, 80% gain, and 0/25/100% peak mix, with identical isolated impulses. The standard preset writer is canonical-only, not a general import utility. DAW preset import has not been verified. The previous eight standard presets can be generated with counterfactual_presets.
