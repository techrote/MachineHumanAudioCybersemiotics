# FX-011H — frequency-selective harmonic memory

Refs #748, #264 and draft #265 at 56c107f8f4147316a588484c47be28bc8f840fbb. Creative DSP extension, not a formal general escape solver or human evidence. Predecessor 6f0a8981db854cc0aa5938f6b7f892ce392235df. No new VST3 adapter or persistent state.

Each band now has a 0..1000 selectivity control blending broadband excitation with a unity-centre-gain Q=4 topology-preserving state-variable bandpass, tuned to the same effective frequency cap (rate/16) as the resonator. Filters track input even at zero selectivity so subsequent changes do not start cold. Zero selectivity keeps the original input arithmetic. Gate closure clears filter history, not the resonator or its pending clock window. Retuning changes coefficients without resetting history. The filter is a selective excitation stage, not a guarantee of spectral separation: the following quantizer is nonlinear and can reject weak or short inputs; phase and timing matter. Set/prepare/reset/process are audio-thread-owned, no mailbox or sample-offset adapter yet. No allocations, locks or I/O in processing; coefficient calculation occurs only on frequency/rate changes. Safe bounded output, no new fixed latency claim. Monitor conservatively: memories can persist indefinitely.

Build `cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build --config Release && ctest --test-dir build -C Release --output-on-failure`. Run `counterfactual_selective_input <existing-output-directory>` to regenerate two original 3-second stereo PCM16 WAVs: 250 Hz sine at 0.35 FS for 0.5 s, two enabled bands at 250/900 Hz, 80% gains, full peak/wet, broadband vs 100% selective. Close gates at 0.5 s, erase both at 2 s. Right silent. At gate closure broadband excites both lattice memories; selective excites only 250 Hz. This is a specific fixture, not universal rejection. The earlier 1 kHz off-band control failed because broadband also reached zero at gate closure; retained as negative evidence, replaced by 900 Hz discriminating fixture. Both final WAVs byte-identical GCC/Clang, original two bank WAVs unchanged.
