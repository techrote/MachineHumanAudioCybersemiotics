# FX-011M — joint stereo optimal erasure (Refs #748)

Direct restricted realization of the minimum-intervention objective in draft #265 at 56c107f8f4147316a588484c47be28bc8f840fbb. For the existing undriven q=9 quarter-turn recurrence, absolute coordinates undergo the same monotone scalar rounding map and permutation. Therefore the maximum magnitude of all four stereo coordinates evolves exactly under that scalar map and reaches zero iff both channels do. Above 4, nearest rounding strictly decreases the maximum and neither action crosses below 4; at 1..4 only truncation decreases it by one. The minimum number of shared interventions is min(m,4), and nearest rounding above 4 followed by truncation attains that budget in the fewest ticks. No graph search or allocation in the callback.

Native `HarmonicBank::beginOptimalEscape(band)` admits only while capture and sustained erase are disabled and no manual intervention is pending. It clears pending drive without resetting the clock/interpolation; reopening capture, a manual pulse, sustained erase, reset or nonzero quantized drive cancels the policy. Completion means discrete states are zero; interpolation drains on the subsequent tick. This momentary mode is not persisted and not yet exposed to VST3. No new parameter IDs or state versions; existing defaults unchanged.

Reproduce with `cmake -S . -B build -DCMAKE_BUILD_TYPE=Release`, `cmake --build build`, `ctest --test-dir build --output-on-failure`; run `build/counterfactual_stereo_escape pure.wav optimal.wav immediate-pure.wav immediate-optimal.wav` for original stereo WAVs. The exhaustive replay checks all 1,185,921 pairs against the previously independently BFS-qualified single-channel policy and verifies the exact maximum-state recurrence at every step. Maximum 4 interventions and 14 ticks; regression and demo silence checks passed on GCC 14.2 Release and Clang 17 ASan/UBSan. The held fixture produces identical PCM tails (9.083 ms); the immediate fixture produces distinct PCM tails (24.979 ms pure, 31.813 ms optimal, whole-file paired RMS difference 0.004080 FS). This is a native demonstration, not a host render or listening assessment. Prior timing and spectral-separation negatives retained. No SDK consumed locally; existing 3.8.0 lock and notices unchanged.
