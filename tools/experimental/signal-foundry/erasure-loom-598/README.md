## Contract

144-sample frames consist of nine contiguous 16-sample chunks. Each lane is a nine-node periodic sample grid. Discard two chunks, separated by 1–4 grid positions, rotated by 0–8 positions. Seven observations uniquely specify a degree-three periodic real trigonometric polynomial. Exact missing-node weights are the source's sine-product formula. Worst-case row L1 gain G=cot(pi/18)/sin(pi*d/9)-1. Nearest surviving left/right circular linear interpolation provides a convex baseline with row L1 norm one. Blend exact and baseline weights with alpha=clamp((B-1)/(G-1),0,1), guaranteeing row L1 <= B before clipping, where B is the user budget. This is a sufficient conservative bound, not an optimal constrained interpolator. Lower budgets deliberately sacrifice exact recovery. The raw branch reads only retained values. Repair multiplies only the missing chunks; zero is deliberate dropout. Stereo channels are independent. Output is bounded to +/-1 FS; budget bounds amplification of retained sample errors, not crest factor of all output. Output protection can violate exact reconstruction. Arbitrary nonperiodic audio is not in the formal model: expect deliberate discontinuities, periodic coloration and potential aliasing. No promise of click-free erasure boundaries. No feedback.

Controls: separation 1–4 (default 4), rotation 0–8 (default 0), budget 1–16 (default 2), repair 0–1 (default 1), wet 0–1 (default .5), wet gain 0–1 (default 1), bypass false. Geometry/budget/repair latch at frame start; wet/gain/bypass use 5 ms full-range slew at output time. Sample API supports external scheduling. Latency 144 samples; tail bound 288 samples because a partially captured block can synthesize later missing samples. At 48 kHz these are 3 and 6 ms. Fixed buffers, precomputed geometry, no allocation/locks/I/O in step(); frame boundary does bounded additional work. Input sanitation clips nonfinite/out-of-range values and zeros magnitudes below 1e-30. Setup range 1 kHz–2 MHz; actual DAW support unqualified.

## Reproduction and audition

CMake 3.16+, C++17. From this directory: `cmake -S . -B build -DCMAKE_BUILD_TYPE=Release`, `cmake --build build --config Release`, `ctest --test-dir build -C Release --output-on-failure`. Run loom_demo in a writable directory. Five original stereo PCM16 WAVs, 48 kHz, four seconds plus 288 samples tail. Reference: wet 0; dropout: repair 0, d=1; adjacent-raw: repair 1, d=1, B=16; adjacent-guarded: d=1 B=2; spread-raw: d=4 B=16. All other demo controls unity, rotation 0. Identical original input across all five, no listening claim. Suggested creative presets use repair .5, wet .3–.5 and budgets 2–4 for less extreme texture.
