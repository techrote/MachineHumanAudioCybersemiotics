Refs #598, #320/#321 (332e1029b30f20cf3f9eab52ac0b21c65c8688e8). A distinct VST3 candidate using the tested incremental three-path engine. This is 192 ms latency at 48 kHz: use DAW delay compensation, not live monitoring. Parameters 1300–1308 mirror the normalized EL02 meanings; 1309 selects fine/medium/coarse (0/.5/1). Default fine, wet .5, gain 1, separation 4, budget 2, repair 1, probe/edge 0, bypass off. EX01 state is 84 little-endian bytes. Reject EL01/02 state rather than silently changing latency of a standard session. Presets: rhythmic dropout (scale 1, repair 0, edge .25, wet 1); spectral weave (scale 0, probe .5, edge .5); guarded fragments (scale .5, budget 2x, probe .5). For examples set normalized budget to 1/15 for 2x. Geometry/probe/edge latch per path frame; wet/gain/bypass and scale are smoothed. No guarantee of seamless arbitrary geometry modulation.
