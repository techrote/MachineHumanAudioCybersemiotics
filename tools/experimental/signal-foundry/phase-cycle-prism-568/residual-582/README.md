## Processing contract

Let D be sanitized input delayed one analysis frame, L the interpolated linear four-bin reconstruction, and Q the identically interpolated modeled nonlinear coefficient increment (raw/corrected blend). The output before safety clipping is

    D + wet * ((gain - 1)*L + gain*Q + (retention - 1)*(D - L))

Retention 1 preserves the broadband residual while injecting only the modeled change; retention 0 reduces to the previous four-bin resynthesis. Gain scales the modeled component, not the retained residual. At drive neutral, gain 1 and retention 1, output is exactly the sanitized delayed input even during grid switches and startup. At settled bypass the output is delayed dry. Retention is smoothed with wet and gain using a bounded 5 ms full-range slew. Grid, drive and cancellation retain their previous frame timing. The residual is complementary to an interpolated estimate, not an orthogonal frame projection during transients. Input is stereo I/Q, not a general stereo distortion remover. Existing incoming partials are not removed by cancellation. Off-bin leakage, finite-window changes and output clipping can invalidate the ideal spectral guarantee. A coherent *unselected* bin is tested, not a general off-grid guarantee.

Uses the inherited four-bin math, exact sample-rate frame sizing and grid factors. Allocation is restricted to prepare; step uses bounded loops and existing finite guards. Latency N, tail bound 3N (600/1800 samples at 48 kHz). API set(Count,value) selects retention, intended future VST parameter 906; no state or adapter changes in this lab. Existing parameter IDs/class IDs untouched.
