# MHAC Projector Lattice — FX-004A

Refs #520, #416/#417 (research draft 0039dbdead33f28b7eefb4ad5680aa05d437ff29, section A finite alphabet of degree-one stages), #504/#506. Base 495a98ca12bae467a507031f04931aa4254b1866. Direct realization of a restricted four-stage projector cascade, not of general dyadic factorization. Audio mapping is creative; no human evidence.

Four stereo stages each delay one of Left, Right, Sum, Difference projections by 1–1024 samples. Set a Program off the audio thread using configure; this clears history and rejects invalid specs transactionally. step is fixed work with preallocated storage; no heap, locks, I/O or logging. Two channels intentionally coupled. No sample-rate dependence: delay is measured in samples. Input/output are double and guarded at +/-1 FS; tiny and invalid values are zeroed. No internal clipping. For exact recovery use conservative input peaks <=1/16 FS, both channels, fixed controls, no intervening processing and cleared histories. The demo uses higher but measured-safe input. Each stage E=I-P+z^d P; complementary projector gives causal inverse F=P+z^d(I-P). Apply these in reverse stage order to obtain pure delay equal to sum of d. Tail of each complete cascade is bounded by sum of d (max 4096). Changing configuration clears history; do not call configure concurrently with processing. No click-free switching, wet/dry, state serialization, float adapter or plugin implemented yet.

## Reproduction

CMake 3.25+, C++17. Run cmake -S . -B build; cmake --build build --config Release; ctest --test-dir build -C Release --output-on-failure. Run lattice_demo from a writable directory. It writes 48 kHz interleaved signed little-endian stereo PCM16, which can be imported as raw audio or wrapped in WAV with Python wave. Example: import wave; w=wave.open('split.wav','wb'); w.setparams((2,2,48000,0,'NONE','not compressed')); w.writeframes(open('split.pcm','rb').read()); w.close(). The preset Sum32, Left127, Difference256, Right511 yields 926 samples reconstruction delay. Original three-second sweep/chord stimulus plus tail, no external audio.
